欢迎来到创忆工坊

先记下来，
再慢慢连起来。

一个念头、一点收获，或一件正在推进的事。
从第一条手记开始，给它们一个安稳的地方。

约 3 分钟下方操作均为示例，不会修改应用里的数据
01 开始记录

想到什么，
就先写下来。

打开首页，直接输入正文，再点「保存手记」。不用先起标题，也不用先想好标签。

草稿会自动保存，方便下次继续写。点「保存手记」后，它才会出现在手记和搜索里。

试着修改文字，再保存这条示例手记
02 分清用途

一条手记，
一个合适的分类。

收获、思绪、待办、完成、其他，对应不同的记录用途。新手记默认选「收获」，也可以随时改选。

事情做完了，把「待办」改为「完成」就好。标签用来补充主题，比如「读书」或「工作」。

切换分类，看看这条记录会放在哪里
03 整理归纳

让零散的收获，
围绕一个主题相遇。

在「主题归纳」里创建一个主题，再用「收录已有手记」把相关记录放到一起。连读时，它们就像一篇逐渐长大的文档。

收录建立的是关联。同一条手记可以属于多个归纳，也一直保留在「手记」列表里。移出归纳不会删除手记。

给「学习方法」收录一条新的手记
04 记录过程

一件长期的事，
一条自己的时间线。

学一项技能、做一个项目，都可以放进「长期事务」。每有一点进展，就「记录动态」，留下当时的行动和想法。

「当前概况」写现在的情况，动态记录过去的过程。需要参考某条手记时，可以关联它，不必再抄一份。

给这个小项目补上一条新进展
05 再次找到

不用记住位置，
记得一个关键词就好。

点开侧栏的搜索，输入你记得的词。手记、归纳、事务和动态都可以找到，再点结果打开内容。

快捷键是 ⌘K（macOS）或 Ctrl+K（Windows）。草稿和回收站里的内容不参与搜索。

试着搜索「记录」或「网站」，再点开结果
06 好好保存

让积累下来的记录，
多一份安心。

进入设置 → 数据与备份，把完整备份存到另一个位置。备份包含记录、关联、草稿和图片，可以用于恢复。

导出适合用其他工具阅读；备份用于恢复整个知识库，两者用途不同。误删的内容可以先去回收站恢复。

点点两种方式，看看各自适合做什么

你可能还想知道

AI 功能需要一开始就配置吗？

可以按需要再开启。在「设置 → AI 服务」保存 API 地址与密钥后，可以使用首页的 AI 建议、搜索问答和按周或月生成的回顾。基础记录与整理无需配置 AI；使用 AI 时，会将对应功能所需的内容发送到你保存的 API 地址，并可能产生服务费用。

记录会保存在网页或服务器上吗？

你的应用记录保存在本机。这个网站只提供使用指引，演示内容也只是示例，不会读取或上传你的知识库。当前不提供设备间自动同步，换电脑时可以使用完整备份迁移。

还没想好如何整理，可以先随便记吗？

当然可以。先写正文、保存手记，分类、标题、标签和关联都可以之后调整。不用把每条记录都整理成完整文章，也不用每天打卡。按照自己的节奏，留下对你有用的东西就好。
