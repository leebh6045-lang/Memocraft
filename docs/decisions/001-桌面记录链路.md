# 首轮桌面记录链路

日期：2026-09-20

## 选择

首轮实现应用外壳和可靠的手记链路。归纳、事务、完整备份恢复与回收站继续按产品规格推进，当前页面明确标注待开放，不预装样例或模拟写入。

Electron 44 内置 `node:sqlite` 已通过本机运行时验证。一个存储 worker 持有唯一连接，主进程经有限 IPC 转交业务请求；渲染端不接触数据库或文件路径。同步短事务按消息顺序执行，备份等后续长操作沿用后台执行边界。

保存草稿与正式提交使用稳定 UUID，正文保持原样，revision 防止旧请求覆盖。正式创建、标签关系和草稿清理在同一事务内。已有手记通过 expectedRevision 更新，成功响应后才更新已保存列表。

客户端分别保留首页与抽屉的编辑现场。若请求结果不确定，保留原请求快照，先重放查证，再提交其后新增的输入；不能在旧请求结果未明时重新生成 ID 或丢弃内容。明确的输入校验错误允许修正内容后重新提交。正常关闭先锁住新编辑并刷新现场，等待期间可取消；收到确认后关闭数据库和窗口，失败保持可恢复的编辑区。

视觉沿用已确定的暖白/深色、固定侧栏、渐进补充、右侧抽屉与左下角搜索，并将动效随组件实现。正式源码用 Vue 与明确状态协调，不搬入原型的内存数据库或页面字符串拼接。

## 代价与复核条件

当前加载全部手记，适合首轮功能验证；数据规模增长后依据实测分页与查询计划优化。搜索返回最多 50 条，空搜索展示最近 5 条。暂不引入全文分词或通用 CRUD 框架。

当前备份验证只覆盖数据库快照及向干净目录恢复，不含附件包、活动库切换或用户入口，不称为完整备份产品。Windows、签名、公证、独立应用图标与发行体验需要后续单独验证。

正文上限 2 MB、标题 300 字符、标签最多 100 个且各 100 字符、搜索词 500 字符，是业务入口的资源边界；超限会明确拒绝且保留输入，后续根据真实记录需求调整。
