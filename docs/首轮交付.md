# 首轮桌面交付 · 2026-09-20

## 本轮成果

已建立可运行的 Electron + Vue + TypeScript 工程，以第四版布局和交互为基准贯通真实 SQLite 手记链路。四分类统一为 `insight / todo / done / misc`，正文只有一份主存储。

已实现：固定四模块导航、浅深主题与专注模式、首页正文/标题/标签/分类、草稿保存恢复、手记创建与更新、分类和标签筛选、最近手记、右侧抽屉、手记搜索及安全 Markdown 预览。归纳与事务页面明确标记尚未开放，创建入口禁用。

数据保护包含修订号、重复提交幂等、正式创建与草稿清理的原子事务、请求响应不确定时重放查证、失败后保留输入，以及正常关闭前处理编辑现场。搜索/抽屉逐层恢复焦点，减少动态偏好受到尊重。数据由 worker 独占连接，preload 只开放有限业务能力。

## 运行与产物

安装、启动及检查命令见 [项目说明](../项目说明.md)。macOS 目录包位于 `release/mac-arm64/Memocraft.app`；默认 Electron 图标、无签名与公证，尚未作为正式版本发布。

构建后可使用以下命令对包内应用运行同一桌面测试；测试自动生成隔离数据目录。

```sh
MEMOCRAFT_TEST_APP="$PWD/release/mac-arm64/Memocraft.app/Contents/MacOS/Memocraft" pnpm test:e2e
```

`MEMOCRAFT_DATA_DIR` 是受控开发/测试启动参数，要求绝对目录，同时隔离数据库与 Chromium 状态。默认开发库与打包库分别位于应用 userData 下的 development/data 与 data，不自动互相迁移。临时测试不接触日常知识库。

## 关键文件与取舍

- `src/renderer/src/composables/useLibrary.ts`：首页和抽屉独立编辑现场，保存次序、错误保留与请求重试。
- `src/renderer/src/components`：分类、卡片、搜索与抽屉；`assets/theme.css` 管理设计令牌与过渡。
- `src/main` 与 `src/preload`：安全窗口、来源校验、worker 生命周期及关闭握手。
- `src/services`：运行时请求校验；`src/storage`：SQL、迁移、数据库快照与干净目录恢复。
- `migrations/001_notes.sql`：当前初始模式，含四分类约束与标签关联；之后用新增迁移升级。

详细设计见 [界面规范](界面与交互基准.md) 与 [首轮架构决定](decisions/001-桌面记录链路.md)。公开规范已更新，早期私人资料和九个原型未改写。
