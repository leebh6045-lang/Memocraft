# 图片缓存修复、连读放大与草稿附图交付 · 2026-09-28

## 交付内容

四件事：修掉「加了图但列表不显示」与「取消选图也提示已添加」两个缺陷；连读里点附图可放大；首页写手记时就能加图片。后两件是新增能力，其中草稿附图需要一次数据库迁移。

### 1. 图片摘要缓存不失效（缺陷修复）

- 现象：给已有手记加图、改名或移出之后，随手记的阅读流与归纳连读仍按加图之前的结论显示——新加的图不出现，移出的图还在，改过的名字也不更新；重启后又正常。
- 原因：列表缩略图的图片摘要按手记 ID「问一次就永久记账」（`asked` 集合只增不减），而图集的增删改名既不属于手记集合、也不触发任何失效，缓存里那份空结果就一直留着。
- 修法：`useNoteImageIndex` 增加 `refresh(noteId)` 与 `reset()`；`useNoteImages` 在成功的增删改名之后回调通知（只针对手记归属）；`App.vue` 接到通知刷新那一条，从备份恢复后整体重置缓存。

### 2. 取消选图不再误报「已添加」

- 现象：点「添加图片」后在系统对话框里取消，图集区仍显示「图片已添加」——什么都没有发生，界面却说成功了（手记详情与首页都有这个问题）。
- 原因：选择对话框取消时主进程返回的是「当前图集」这样一个成功结果，渲染端无法区分「取消了」和「加好了」，于是照常写下成功文案。
- 修法：取消时 `addImagesFromDialog` 返回 `null`（契约注释写明），图集现场遇到 `null` 就既不写状态、也不改图集、也不刷新摘要——没有写入就没有提示。
- 同时收紧了图集区的文案：提示压成一行「可粘贴图片，单张不超过 20 MB。」，空图集只说「还没有图片。」；顺手删掉已经用不到的 `disabled` 与 `emptyText` 两个属性（图片现在草稿也能加，那个「先保存这条手记」的分支已经失效）。

### 2.1 草稿区的图集再简化（同日反馈）

- 草稿区只留「＋ 添加图片」与一句「（支持粘贴图片）」：不再有「图片」标题、限制说明与空状态文案；有图时照常显示缩略图网格。两段文字同字号、去掉通用提示的上边距，实测基线一致。
- 成功与失败改用一句提示条：「粘贴失败」「添加图片失败」「改名失败」「移出失败」；粘贴或选择超过 20 MB 的图片因此只弹一句「粘贴失败」，不再铺原因说明。手记详情里的图集仍保留完整说明与详细原因。
- 编辑区对齐修正：正文、图片区、补充区、底部操作栏此前各用各的左右留白（24 / 18 / 18 / 14px），补开补充区后文字明显不齐。现在统一为 24px，分隔线也一起内缩。

### 3. 连读里点附图放大查看

- 把原来写在图集组件里的放大层抽成 `ImageViewer.vue`：自己管理当前张数与上一张 / 下一张，进入模态层后接管焦点与 Tab 范围，卸载时把焦点还给打开它的那个缩略图，Esc 只关这一层。
- 归纳连读的小节里，附图从静态图片改成可聚焦按钮，点击即用同一层放大，仍可翻上一张 / 下一张。首页草稿与手记详情复用同一层，三处交互一致。
- 图集组件因此瘦身：删掉重复的放大层状态、键盘处理与样式。

### 4. 首页草稿就能加图片

- 首页编辑器的结构变为「正文 — 图片 — 补充 — 底部操作」：正文下方的图片区可以粘贴剪贴板图片、或点「添加图片」选文件，有图时是与手记详情同形的缩略图网格（名称输入框、「移出」二次确认、点击放大）；整块编辑区都能接收粘贴，纯文本粘贴不受影响。
- 保存手记之前图片归属这份草稿，`commitDraft` 在同一个事务里把图片改成这条手记的图片并删除草稿行；保存后首页换成空图集的新草稿，重启后图片仍在这条手记下。
- 草稿行还没落盘时（全新草稿、内容没变）先经 `useLibrary.ensureDraftStored()` 保存一次，再写图片：拿不到归属就不写，并说明「草稿还没有保存成功，图片没有添加」。
- 数据模型见 [决策 004](decisions/004-首页草稿附图.md)；迁移 `005_draft_images.sql` 重建 `note_images`，模式版本 4 → 5。

## 数据兼容与恢复

- 新增迁移 `005_draft_images.sql`：重建 `note_images` 以放宽 `note_id` 并加入 `draft_id`，现有图片行全部原样复制，**不丢数据**；模式版本 4 → 5。
- 旧版本代码打不开升级后的库（版本比程序新会明确拒绝并保留原文件）。要回退代码，需先备份数据库，再把 `user_version` 降回 4 并移除 `draft_id` 列与两个索引，最后复核 `PRAGMA integrity_check` 与 `PRAGMA foreign_key_check`。
- 草稿附图属于用户数据：备份的附件包与数据库快照都包含它们；恢复后草稿与图片一起回来。

## 已知限制

- 被丢弃且未保存的草稿会留下孤儿图片记录与文件（不自动清理，与软删除图片的处置一致）。
- 草稿图集上限与手记一致（50 张 / 200 MB），提示文案仍写「每条手记」，指同一条归属记录。
- 阅读流一次渲染整列 Markdown 的性能仍未测量；与上一轮相同。
- 仍未修复的遗留项：[App.vue](../src/renderer/src/App.vue) 的切页滚动记忆与 [ThreadsPage.vue](../src/renderer/src/pages/ThreadsPage.vue) 的「回到列表顶部」仍在操作 `window`，而实际滚动容器是 `.main`。
