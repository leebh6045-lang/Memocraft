# 随手记呈现方式与归纳目录交付 · 2026-09-27

> 后续调整见 [归纳连读与呈现调整交付](归纳连读与呈现调整交付.md)：工具栏改为整组右对齐、阅读流去掉「按时间分段」勾选框并默认分段、分段文案与位置调整、阅读流增加附图缩略图。

## 交付内容

随手记在原有网格之外新增**阅读流**与**按时间**两种呈现，按时间另有两种分段方式；知识归纳列表在原有卡片之外新增**目录**排列。改动只在渲染端，不涉及 IPC、SQLite 与迁移。网格卡片本身（标题、摘要、标签）保持原样。

### 1. 随手记的呈现方式

- 入口在标签筛选右侧：分段控件「网格 · 阅读流 · 按时间」；选「按时间」时，右侧再出现「分段」下拉框。没有别的新增控件，页面结构不变。
- **网格**：默认，与改版前完全一致。
- **阅读流**：单列宽卡片，正文用与抽屉预览同一份渲染器（禁用 HTML、图片与链接）直接显示 Markdown，超过约 8 行淡出；整张卡片可点开抽屉，拖选正文复制时不打开；标题按钮是键盘入口。没填标题时正文不再重复用作标题的首行。
  - 可选「按时间分段」叠加日期栏，分段方式与「按时间」共用；按天分出的段里卡片只写时刻。
- **按时间**：左侧日期栏随滚动吸附，右侧仍是网格卡片；段与段之间只有细线，不画时间线，和长期事务区分开。
  - 分段方式：「近一周按天，更早按月」（默认；近一周是今天与往前 6 个日历日）与「一律按天」。
  - 按天：大号日期、「9月 · 周日」，今天 / 昨天带标记，段内卡片只写时刻（日期已在日期栏上）。
  - 按月：「9月」「8月」，本月写「本月更早」，跨年写年份；段内卡片仍按统一时间规则。
- 分类、标签筛选在三种呈现下照常生效，无匹配时显示同一个空结果。

### 2. 归纳目录

- 入口在页头「新建归纳」左侧：「卡片 · 目录」。
- 目录不画卡片框：大号序号、标题、引导点线与条数；下一行是说明（没有说明不占位）、创建时间与最新一条手记的时间；再列出最新 3 条手记，点击直接打开手记抽屉；超过 3 条给「查看全部 N 条」进入详情。
- 同一条手记还收录在其他归纳时标「另见 N」，悬停提示与可读名称给出那些归纳的名字。
- 只影响列表页，归纳详情不变；从目录进入详情同样有标题的共享元素过渡。

### 3. 偏好保存

三项选择（随手记呈现、分段方式、归纳排列）加上阅读流的「按时间分段」开关，与主题偏好同一做法，存在本机 `localStorage`，不进数据库，重启后保持。读到未知值或读取失败时退回默认（网格 / 近一周按天 / 卡片）；写入失败时照常切换，用提示条说明「偏好未能保存，重启后会回到默认呈现」。

> 阅读流的「按时间分段」开关已在后续调整中取消（阅读流固定按时间分段），那项偏好不再读写；旧键留在本机不影响任何行为。

## 已知限制

- 阅读流一次渲染全部手记的 Markdown；手记数量很大时的滚动性能未做测量，出现卡顿再按可见区渲染。
- 阅读流不显示附图缩略图：图集目前只按单条手记读取，列表里显示需要另设批量读取。
- 归纳详情里卡片外包 `.topic-note`，同一行卡片高度可能不齐（用户待办「归纳内出现卡片尺寸异常」多半源于此），本次按要求未改动详情页。
