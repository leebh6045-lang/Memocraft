# Memocraft 界面与交互基准

本规范是界面实现与验收的唯一依据。产品行为以 [产品规格](产品规格.md) 为准，代码与验证遵循 [开发准则](开发准则.md)；逐条差异与裁决记录见 [V2 实施规划](V2实施规划.md) 第 3 节。

**V2 起的裁决口径**：视觉、布局、控件互动与文案以选定原型「方案 D · 流畅」为准；数据保护、无障碍、失败路径与持久化条款沿用本项目既有要求，**不因原型未体现而降低**。原型是静态演示，不含真实存储、并发与无障碍处理，凡本规范与原型不同处，均按本规范执行。

## 1. 范围

第一次交付贯通首页草稿、保存手记、随手记列表、分类和标签筛选、抽屉编辑、手记搜索，建立桌面外壳、主题和专注模式。V1.5 在同一外壳内加入手记图片图集。V2 依次接入知识归纳与多重收录、长期事务与动态、全对象搜索、回收站、完整备份恢复与可读导出。

未提供入口的能力不能被描述为已交付，也不用成功提示模拟未完成操作。

**两处对原型的刻意收紧**（原型未限制，本项目保留更严的做法，理由随条目标注）：

1. 手记卡片标题限制两行、摘要三行。原型不截断标题，但两列网格下长标题会撑高卡片、破坏列表节奏；长正文完整内容在抽屉中阅读。
2. 深浅主题切换必须先锁定旧主题的计算样式再切换变量（原型直接切类）。原型不做处理会出现文字先闪到新颜色；时长归入三档（见第 5 节）。

浅色采用暖白背景 `#f7f6f3`、白色表面、深灰正文 `#25242a`、克制的蓝色强调 `#3b5b7c`。深色采用背景 `#17181c`、表面 `#1f2025`、正文 `#e8e7ec`、强调 `#8fb0d6`。辅助文字可适度提高对比度，不能只靠很浅的文字表达操作结果。两种主题的层级和布局一致。

系统中文无衬线字体用于界面，系统等宽字体用于代码和快捷键。正文默认 15px、首页输入 16px、页标题 24px。长标题和标签不得撑破容器，代码片段保留原文；预览必须安全渲染或以文本显示，不能执行手记内容。

时间显示沿用统一格式：当天显示「今天 HH:MM」，前一天显示「昨天 HH:MM」，同年显示「MM.DD HH:MM」，跨年显示「YYYY.MM.DD」；卡片与列表按同样规则，不混用其他写法。**唯一例外**是随手记「按时间」呈现里按天分出的段：日期已写在左侧日期栏上，段内卡片只写「HH:MM」；按月合并的段仍按统一规则。

## 3. 核心控件

首页“正文—图片—补充—底部操作”处于同一编辑器内，四段顺序固定。**图片区紧跟正文，左右与正文对齐**（分隔线与缩略图都不顶到编辑器边框，留白由编辑区提供）：草稿区只放「＋ 添加图片」与一句「（支持粘贴图片）」，没有标题、限制说明与空状态文案；有图时与手记详情同形的缩略图网格（名称输入框、「移出」二次确认、点击放大）。图集的成功与失败都用提示条反馈，文案从简——粘贴超限就是「粘贴失败」，且**取图对话框被取消时不提示成功**：没有写入就没有「已添加」。手记详情里的图集仍保留标题、限制说明与空状态文案。保存手记之前图片归属这份草稿，保存后成为这条手记的图片，新草稿从空图集开始。补充按需展开标题、标签、收录到归纳与关联事务，保持编辑器位置连续，关闭的表单不能接收键盘焦点；补充按钮显示当前已填条目数。**标签在补充区只有「已选胶囊 + ＋ 选择标签」一行**：点它打开右侧「选择标签」抽屉，15 个预设标签按四组（学到与想到／做法／经历／生活）排开点选，抽屉底部可加自定义标签；点标签不关抽屉，可连续多选，「完成」或 `Esc` 收起。已选胶囊带 `×`，删标签不必再开抽屉。分类顺序为收获、待办、完成、杂项，默认收获；原生单选语义与滑动选中底块共同表达状态，不另设完成复选框。

最近手记是首页次要区域，支持进入同一份手记详情。随手记默认全部，按创建时间倒序；分类与标签筛选无匹配时明确显示空结果，不自动回退。卡片显示分类、创建时间、标题、摘要与标签。**标签是淡底药丸（保留 `#` 前缀）**，与正文、时间一眼分开；被收录过的手记在标签之后追加一枚**同尺寸的蓝色胶囊**：收录到一个归纳写「已收录」，多个写「已收录 · 2」，悬停提示与可读名称给出归纳名字。**卡片上不再出现「收录于 X」**，归纳名字只留在提示与手记详情里；未被收录的手记不显示任何标记，归纳详情里的手记也不显示（那里每条都已经在这个归纳里）。

**随手记的呈现方式**在工具栏最右侧切换（分段控件「网格 · 阅读流 · 按时间」）：标签筛选留在左边，呈现设置整组靠右，**分段方式在左、呈现方式在最右**，窄窗换行时仍保持这一组靠右。它只改变怎么摆，不改变筛选结果与创建时间倒序；选择存在本机、重启后保持，读取失败回到网格，写入失败时照常切换并用提示条说明未能保存。

- **网格**（默认）：即上面描述的两列卡片，不分组，因此不显示分段方式。
- **阅读流**：单列宽卡片，顶部分类、时间与附图张数，标题是键盘入口，正文用与抽屉预览同一份安全渲染器直接显示 Markdown，超过约 8 行淡出，正文下方最多露出三张附图缩略图（120×84 裁切，多于三张只写 `+N`，懒加载；读不到时留占位，不影响正文）；整张卡片可点开抽屉，拖选正文时不打开。没填标题时标题取自正文首行，阅读流的正文不再重复这一行。**阅读流默认按时间分段**，没有开关：与「按时间」一样出现日期栏，两者共用同一个分段方式。
- **按时间**：左侧 68px 日期栏随滚动吸附在顶部，右侧仍是网格卡片；段与段之间只用细线分隔，不画连线与节点，与长期事务的时间线区分开。分段方式在呈现切换左侧的下拉框里选，**不写「分段」二字**（可读名称仍为「按时间分段的方式」）：「最近优先」（默认；最近一周逐日、更早按月合并）或「一律按天」。按天的日期栏写大号日、「月 · 周几」，今天 / 昨天另带标记；按月的写「N月」，本月写「本月更早」，跨年写年份；每段写条数。

抽屉保留背后列表的位置。关闭前处理未保存编辑，成功后列表和搜索使用更新后的同一份数据；保存失败保留抽屉与输入，允许重试。首页草稿与已有手记的编辑现场互不覆盖。

抽屉自上而下依次为：分类选择与关闭按钮、可编辑标题与正文、标签、**「收录于归纳」**（这里的标签**只有逗号分隔的手写输入框**，不提供预设点选——预设点选只在创建手记时的「选择标签」抽屉里，避免抽屉上再开抽屉）、**「被引用的位置」**、图片图集，底部显示创建与修改时间以及「移到回收站」。「收录于归纳」列出所属归纳并可跳转，提供「收录到归纳」入口——它打开的是**归纳选择器**（列出全部归纳、已收录的带「已收录」标记且不可重复选择，并可就地新建归纳），选择器提交后才产生收录；「被引用的位置」列出引用该手记的动态与事务，没有引用时用一句话说明，不留空白。收录、移出与关联失败时就地给出原因（写清是哪个对象、为什么），不允许静默失败。

抽屉在正文与关系区之后是图片图集区：空状态说明可用「添加图片」或直接粘贴；有图时是缩略图网格，每张下方是可编辑的名称输入框与「移出」按钮。移出需要二次确认，首次点击只把按钮文案变为「确认移出」。缩略图是可聚焦按钮，可读名称包含图片显示名称；加载失败显示占位而不是破图。图集操作独立于正文编辑现场，只改图片不会让正在编辑的正文判成冲突。

点击缩略图打开放大层：居中显示、等比缩放、不超过视口，提供上一张/下一张与「关闭」。放大层是抽屉之上的一层模态浮层：Esc 先关放大层而不是整个抽屉，Tab 限制在放大层内，关闭后焦点回到触发它的缩略图。图集状态（加载中、失败、已保存）分别表达，失败保留已有图片并给出原因，界面不显示尚未落库的图片。

归纳与事务列表使用集合卡片：含序号、标题、说明、收录数量或动态数量与最近时间；事务卡片含「进行中／已归档」状态胶囊，已归档卡片整体降低对比度。**归纳列表另可切换为目录**，见下一段。归纳详情与事务详情使用面包屑返回列表，页面顶部只读呈现标题（事务另带状态胶囊），**基础信息（标题、说明、事务的当前概况）不占页面位置**，统一由「编辑基础信息」唤出右侧抽屉填写并自动保存，删除入口只放在该抽屉底部。事务详情在标题下方直接是动态区：左侧「动态 N」与正倒序切换，右侧「＋ 记录动态」唤出抽屉填写（发生时间、详细内容、标签与引用手记），时间线每条含发生时间、描述、正文与引用手记 chip。直接关联的手记留在时间线下方，不因基础信息收进抽屉而移位。进入归纳与进入事务详情使用同一种共享元素过渡，标题从卡片位置连续移动到详情标题。

**归纳目录**：页头「新建归纳」左侧是「卡片 · 目录」切换，选择存在本机，读写失败的处理同随手记呈现。目录不画卡片框，每个归纳是大号序号、标题、引导点线与条数；下一行是说明（没有说明不占位），再下一行是创建时间与最新一条手记的时间；然后列出最新 3 条手记（分类圆点、标题、时间，点击打开手记抽屉），超过 3 条时给「查看全部 N 条」进入详情。同一条手记还收录在其他归纳时标「另见 N」，悬停提示与可读名称给出那些归纳的名字。目录只影响列表，归纳详情不变，标题同样以共享元素过渡进入详情。

**归纳详情**：标题下方一行左边是说明（作为导语只读显示，没有说明不占位）与「N 条手记 · 创建于 …」，右边是两组分段控件——**排列顺序**「最新在前 · 最早在前」与**呈现方式**「连读 · 网格」，两项都存在本机、重启后保持，读写失败的处理同随手记呈现。顺序对两种呈现同时生效；网格就是原来的两列卡片，每条手记悬停时出现「移出」。

**连读**（归纳详情默认）：收录的手记连成一篇文档，每条一个带序号的小节——序号与标题、分类 / 时间 / 标签（含「另见『X』」，可跳到还收录了这条手记的其他归纳）、完整 Markdown 正文与附图缩略图。右侧 164px「本页目录」随滚动高亮当前小节（滚到底时最后一节也高亮），点击某项平滑滚动到该节并让开固定标题栏；悬停或键盘聚焦小节时，右上角出现「打开」（进手记抽屉）与「移出」（从本归纳移出，用提示条撤销）。窄窗（≤900px）隐藏右侧目录，正文单列，其余不变。

**回顾**：页头保留周/月滑动分段控件；点击周期标签展开最近 12 周或 12 个月的倒序列表，显示选中勾与本周/月徽章，不列未来项。正文直接平铺在背景上，章节间以 1px 细线分隔；「总结」为主体，15px/1.9 按主题分点、加粗短标题，首要主题展开、其他方向简略，完整展示。建议为圆点无序列表，用缩进和点间距区分、条目不画横线；覆盖条数、生成时间与重新生成在底部。首次加载用 3 行参差宽度的文字骨架，空期、错误与未配置均为平铺文字和按钮。键盘、焦点、缓存与取消细节见 [周期回顾设计](features/ai/2026-10-AI周期总结-设计.md)。

**提示条**用于报告已完成的操作，位于底部居中、深色底、默认约 3.6 秒后自动消失（即使携带操作按钮也照常消失，悬停不暂停），可携带一个操作。涉及可逆操作的提示条必须提供撤销：从归纳移出、删除动态、修改分类等；撤销只在提示条存续期间有效，过期后按回收站流程恢复。

**对话框**用于新建归纳与事务、选择手记、选择归纳、确认删除。对话框使用原生模态语义，打开时焦点进入首个输入项，关闭后回到触发元素；空候选时给出说明；同名标题不静默改名，由用户确认。删除确认必须写明受影响的范围与保留的内容。

**选择器**在手记与归纳两个方向上共用同一套交互与外观，区别只在条目与文案：归纳侧列手记（已经在这个归纳里的不再列出，只回报数量），手记侧列归纳（全部列出，已收录的带标记且不可重复选择）。两侧都支持搜索、多选后一次提交，多选时显示「已选 N 条」或「已选 N 个」；手记侧还提供「＋ 新建归纳」，创建成功后新归纳直接勾上，和已勾选的归纳一起提交。

**回收站**入口是左下角「内测中」右侧的第一个图标按钮，不与搜索、专注、主题挤在同一组工具区。页面用行列表而非卡片网格，每行显示对象类型、标题、来源上下文（如「原属归纳：…」「原属事务：…」）、删除时间与「恢复」；顶部按对象类型筛选；页面开头用一句话说明删除事务会连带动效、恢复事务不会恢复此前单独删除的动态、回收站内容不参与搜索。空状态说明这里保存已删除内容且不提供自动清空与永久删除。

**设置**入口是左下角「内测中」右侧的第二个图标按钮（回收站之后），快捷键 `⌘,`，页面分「外观」「数据」「关于」三区。阶段 1 先落地外观与关于：外观区提供主题三选（浅色 / 深色 / 跟随系统）并说明偏好保存在本机、重启后保持，侧栏的主题按钮保留为浅色与深色之间的快速切换；关于区显示内测标识、数据库类型与图片存放位置，不展示本机绝对路径，应用尚未向界面提供版本号，发行阶段再补。数据区集中放置备份、恢复与导出：备份显示上次备份时间与体积；恢复分两步——先校验并显示备份内容统计，再由模态确认写明影响范围与不可取消；导出说明只用于阅读与迁移参考、不能代替备份。进行中的长任务如实显示「进行中 · 不能取消」，进度为不确定态，不使用假百分比。

全局搜索位于左下工具区，支持 `⌘K / Ctrl+K`。搜索覆盖手记、归纳、事务与动态（见产品规格），结果按对象类型分组，每行为类型列 + 标题 + 上下文列；标题命中处高亮，命中在正文时用上下文列显示命中摘要。结果可直接打开：手记进抽屉，归纳与事务进各自详情，动态定位到所属事务。空输入展示最近内容，分组标题必须与实际含义一致（写清对象类型，不使用同名分组或凭空的「最近访问」）；草稿与回收站内容不参与。没有匹配项、查询失败与正在查询必须分别表达。

## 4. 按键与快捷操作

**AI 设置增量**：模型与密钥之间增加「API 地址（Base URL）」输入，默认 `https://api.deepseek.com`，支持自定义兼容服务、保存地址、恢复官方；留空保存也恢复官方。地址草稿有未保存改动时禁用测试，保存失败保留输入与原配置；测试期间锁定地址。成功回填规范地址，编辑清除旧测试结果；普通备份或导出后的配置重读不丢地址草稿，恢复实际改变配置时刷新地址。隐私说明采用「发送到已保存的 API 地址」，详见 [自定义地址设计](features/ai/2026-10-AI自定义地址-设计.md)。

| 按键                | 行为                                                               |
| ------------------- | ------------------------------------------------------------------ |
| `⌘/Ctrl + 1–4`      | 切换首页、随手记、知识归纳、长期事务                               |
| `⌘/Ctrl + K`        | 打开搜索                                                           |
| `⌘/Ctrl + Enter`    | 保存首页手记；焦点在动态输入区时提交该条动态                       |
| `Esc`               | 依次关闭最上层浮层（对话框或搜索 → 抽屉 → 放大层）后再退出专注模式 |
| `⌘/Ctrl + ,`        | 打开设置                                                           |
| `↑` `↓` `Enter`     | 搜索内移动与打开，选中项滚动到可见区域                             |
| `Enter`（标签输入） | 添加标签                                                           |

快捷键通过统一入口处理，不因组件重新挂载而叠加监听器。中文输入法合成期间，回车、Esc 和快捷键不能触发保存、关闭、选择搜索结果等冲突操作。

## 5. 动效与反馈

常规动效使用 140ms、240ms、320ms 三档时长，常规缓动为 `cubic-bezier(.2,.8,.2,1)`，浮层进入为 `cubic-bezier(.16,1,.3,1)`。回顾内容入场按用户选定的凝结节奏单独定义，见下文。

| 行为       | 动效要求                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| 按钮与悬停 | 140ms 颜色、边框和轻微按压反馈；卡片悬停上移 2px                                                           |
| 模块切换   | 140ms 淡出并上移 6px，240ms 从下方 8px 淡入；侧栏底块 320ms 连续滑动                                       |
| 列表到详情 | 归纳与事务进入详情使用共享元素过渡，标题从卡片位置连续移动；减少动态时即时切换                             |
| 分类改选   | 320ms 选中底块移动，文字状态与实际分类一致                                                                 |
| 补充展开   | 320ms 高度展开，240ms 淡入，不在动画结束前清除字段                                                         |
| 列表重排   | 320ms 平滑重排，新增项约 260ms 并逐项错开出现；移除项不挤占最终布局                                        |
| 新增高亮   | 新建或新收录的卡片、行、动态短暂高亮后回到常态，不影响可查找性                                             |
| 抽屉       | 320ms 从右侧进入，遮罩同步淡入淡出；手记详情、基础信息、记录动态、选择标签四类抽屉共用同一进出场与焦点规则 |
| 搜索       | 遮罩与面板 240ms 淡入淡出；独立模糊层 320ms 渐显/渐隐，面板 320ms 轻微位移和缩放                           |
| 提示条     | 进入 320ms 自下淡入，离开 240ms 淡出                                                                       |
| 对话框     | 进入 320ms 淡入并轻微上移，关闭 140ms 淡出                                                                 |
| 保存成功   | 只在真实持久化成功后反馈；按钮切换为「已保存」后复位                                                       |
| 内容为空   | 正文为空时提交，编辑区短促抖动并把焦点移回正文，提示需要先输入内容                                         |
| 图片图集   | 缩略图网格沿用列表重排时长；放大层与抽屉遮罩同为 320ms 进出，减少动态下即时完成                            |

动画不能决定业务完成时机，不能用定时器假装保存成功。快速连续切换以最后一次有效意图为准，不闪回旧页面，不由旧请求覆盖新数据。系统启用减少动态时，移位、缩放、循环提示和过渡应近乎即时，交互语义与内容保留不受影响；列表重排、共享元素过渡与抖动同样跳过。

回顾页进入、周期切换和新结果出现仅使用「凝结」：透明度先显现、8px 模糊线性收敛，位移仅 5px；总结标题与正文先出现，随后章节细线、推荐、底部信息依次凝实，不叠加模块整体上移入场。离场为 140ms 淡出，滑块与内容高度仍为 320ms；具体分块延迟见 [周期总结设计](features/ai/2026-10-AI周期总结-设计.md)。减少动态时立即清晰并恢复自然高度。侧栏「回顾」左侧使用用户提供的 `rili.svg` 日历图形，保留轮廓、18px 大小、颜色跟随导航文字；右侧靠右显示与「AI 建议」相同的四角星芒，蓝紫粉金渐变描边，深浅主题一致，装饰图标不增加按钮朗读内容。

草稿与保存状态文案固定为：空白时不保存并说明原因、写入中显示“正在保存草稿…”、成功后显示“草稿已保存 时间”。

## 6. 输入、焦点与数据保护

- 启动恢复草稿后可直接输入。每次输入先标记尚未保存，再根据实际请求显示保存中、已保存或失败；不能因防抖尚未发请求就显示已保存。
- 导航和正常关闭先处理待保存内容，失败保留当前编辑并允许重试或取消离开。正式保存期间防止重复提交；重试不能重复创建记录。
- `⌘Enter / Ctrl+Enter` 保存首页手记；抽屉修改自动保存。搜索支持上下方向键选择和回车打开；异步旧查询不能覆盖较新的关键词结果。
- 搜索与抽屉遵循模态焦点范围，背景不可交互；关闭恢复此前触发元素及必要的输入光标位置。原触发元素消失时恢复至合理的页面入口。Esc 优先关闭最上层浮层，再退出专注模式。
- 专注模式收起侧栏及首页次要区域，正文保持居中；保留明确退出方式。隐藏控件不能继续接收焦点。
- 分层浮层的 Tab 限制在当刻真正可见的那一层：放大层打开时锁定放大层，关闭后回到抽屉，再关闭才回到列表。
- 深浅主题切换先锁定旧主题的计算样式，再在同一过渡窗口内改变颜色、边框、阴影和图标描边；不能出现文字或控件先闪变后过渡。外观偏好需要持久化，重启后保持。
- Tab 焦点清晰可见，按钮有可读名称，图标为装饰时不重复朗读。加载、失败和保存状态通过适当的无障碍提示区域传达。
- 撤销、归档、移出等可逆操作要有明确的可逆边界；不可逆或高风险操作（恢复数据、替换当前库）必须在确认文案中说明影响范围。

## 7. 交付检查

与基准同时对照浅色、深色和专注模式，在常用尺寸及最小窗口验证首页、列表、抽屉和搜索；使用长中文标题、多标签、长正文及代码块检查溢出。实际操作连续切页、中文选字、分类方向键、浮层焦点循环与恢复、搜索快速改词及减少动态设置。

草稿与保存流程还需验证重启恢复、保存失败保留、重复提交不重复创建、已有手记修改同步与搜索一致。图片图集需验证粘贴与选择、单独命名、放大与关闭后的焦点回位、移出确认、重启后仍在，以及备份恢复后图片仍可显示。**首页草稿的图集**另需验证：在全新草稿里直接粘贴图片（草稿自动先落盘）、图片随保存转成这条手记的图片、保存后首页图集回到空、重启后图片仍在这条手记下。V2 各阶段新增界面需验证收录与引用的反查一致、时间线排序与补录、提示条撤销的有效期、对话框焦点归还。呈现方式与归纳详情另需验证：三种呈现切换后筛选与打开抽屉照常、阅读流按时间分段且显示附图缩略图、归纳内卡片同一行宽高一致、连读的目录随滚动高亮与「打开 / 移出」、连读里点附图放大、顺序与呈现选择重启后保持。视觉检查不能代替 SQLite 与桌面生命周期的实际验证。每项检查如实记录通过、失败或未运行，平台声明仅覆盖实际验证的平台。

搜索的模糊层、暗色遮罩与面板作为同级元素分别过渡；共同父层不设置透明度或滤镜，避免改变背景采样边界而在动画结束时突变。模糊层保持固定滤镜，通过透明度连续混合清晰与模糊背景。退出等待全部子层过渡完成，系统减少动态偏好开启时即时完成。
