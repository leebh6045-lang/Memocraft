# Memocraft 界面与交互基准

本规范将已选定的第四版界面设计转为正式实现与验收依据。产品行为以 [产品规格](产品规格.md) 为准，代码与验证遵循 [开发准则](开发准则.md)。本文件描述目标与约束，实际已验证范围记录在交付文档中。

## 1. 本轮范围与 v1 的区别

第一次交付贯通首页草稿、保存手记、随手记列表、分类和标签筛选、抽屉编辑、手记搜索，建立桌面外壳、主题和专注模式。知识归纳与长期事务保留正式导航位置，显示明确的“尚未开放”状态，新建按钮禁用；不放假数据，不用成功提示模拟未完成操作。

v1 将接入归纳、收录关系、事务动态及其引用，搜索届时覆盖四类实体。回收站、完整备份恢复与导出等 v1 范围见产品规格；本轮界面没有提供入口的能力不能被描述为已交付。

## 2. 布局与视觉

| 项目     | 基准                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| 标题栏   | 为真实桌面窗口预留 34px 拖动区，不展示原型说明条                                                     |
| 侧栏     | 224px；仅显示 `Memocraft` 品牌名，四模块固定顺序排列，搜索、专注、主题工具靠下                       |
| 发行标识 | 左下角固定显示“内测中”，不随切页或专注模式消失                                                       |
| 内容容器 | 最大宽度 820px，包含左右各 48px 内边距；通常顶部 44px、底部 90px                                     |
| 小窗口   | 桌面最小 1000 × 700；1000–1050px 宽度将内容左右边距收至 32px，避免按钮拥挤                           |
| 卡片     | 两列、间隔 14px；内边距 18px 20px，10px 圆角；标题最多两行、正文摘要三行                             |
| 编辑器   | 白色或深色表面，10px 圆角，正文最小高度 200px；正文先于可选属性                                      |
| 抽屉     | 右侧宽 560px，最大 92vw；标题栏以下展开，正文区独立滚动，操作区可见                                  |
| 搜索     | 居中宽 640px，最大 92vw，顶部约 14vh；背景遮罩的透明度与模糊强度同步渐变，列表超过可见区域后内部滚动 |

浅色采用暖白背景 `#f7f6f3`、白色表面、深灰正文 `#25242a`、克制的蓝色强调 `#3b5b7c`。深色采用背景 `#17181c`、表面 `#1f2025`、正文 `#e8e7ec`、强调 `#8fb0d6`。辅助文字可适度提高对比度，不能只靠很浅的文字表达操作结果。两种主题的层级和布局一致。

系统中文无衬线字体用于界面，系统等宽字体用于代码和快捷键。正文默认 15px、首页输入 16px、页标题 24px。长标题和标签不得撑破容器，代码片段保留原文；预览必须安全渲染或以文本显示，不能执行手记内容。

## 3. 核心控件

首页“正文—补充—底部操作”处于同一编辑器内。补充按需展开标题与标签，保持编辑器位置连续，关闭的表单不能接收键盘焦点。分类顺序为收获、待办、完成、杂项，默认收获；原生单选语义与滑动选中底块共同表达状态，不另设完成复选框。

最近手记是首页次要区域，支持进入同一份手记详情。随手记默认全部，按创建时间倒序；分类与标签筛选无匹配时明确显示空结果，不自动回退。卡片显示分类、创建日期、标题、摘要、标签，不展示不存在的关联数量。

抽屉保留背后列表的位置。关闭前处理未保存编辑，成功后列表和搜索使用更新后的同一份数据；保存失败保留抽屉与输入，允许重试。首页草稿与已有手记的编辑现场互不覆盖。

全局搜索位于左下工具区，支持 `⌘K / Ctrl+K`。本轮搜索提示明确检索手记，支持标题、正文、标签的子串匹配，中文原文、英文大小写和普通符号按产品规格处理。草稿不计入搜索。空输入可展示最近手记；没有匹配项、查询失败与正在查询必须分别表达。

## 4. 动效与反馈

统一使用 140ms、240ms、320ms 三档时长，常规缓动为 `cubic-bezier(.2,.8,.2,1)`，浮层进入为 `cubic-bezier(.16,1,.3,1)`。

| 行为       | 动效要求                                                                         |
| ---------- | -------------------------------------------------------------------------------- |
| 按钮与悬停 | 140ms 颜色、边框和轻微按压反馈；卡片悬停上移 2px                                 |
| 模块切换   | 140ms 淡出并上移 6px，240ms 从下方 8px 淡入；侧栏底块 320ms 连续滑动             |
| 分类改选   | 320ms 选中底块移动，文字状态与实际分类一致                                       |
| 补充展开   | 320ms 高度展开，240ms 淡入，不在动画结束前清除字段                               |
| 卡片筛选   | 320ms 平滑重排；移除项不挤占最终布局                                             |
| 抽屉       | 320ms 从右侧进入，遮罩同步淡入淡出                                               |
| 搜索       | 遮罩与面板 240ms 淡入淡出；独立模糊层 320ms 渐显/渐隐，面板 320ms 轻微位移和缩放 |
| 保存成功   | 只在真实持久化成功后反馈；新增条目短暂高亮，反馈不代替可查找的记录               |

动画不能决定业务完成时机，不能用定时器假装保存成功。快速连续切换以最后一次有效意图为准，不闪回旧页面，不由旧请求覆盖新数据。系统启用减少动态时，移位、缩放、循环提示和过渡应近乎即时，交互语义与内容保留不受影响。

## 5. 输入、焦点与数据保护

- 启动恢复草稿后可直接输入。每次输入先标记尚未保存，再根据实际请求显示保存中、已保存或失败；不能因防抖尚未发请求就显示已保存。
- 导航和正常关闭先处理待保存内容，失败保留当前编辑并允许重试或取消离开。正式保存期间防止重复提交；重试不能重复创建记录。
- 中文输入法合成期间，回车、Esc 和快捷键不能触发保存、关闭、选择搜索结果等冲突操作。
- `⌘Enter / Ctrl+Enter` 保存首页手记；抽屉修改自动保存；`⌘1–4 / Ctrl+1–4` 切换四模块。快捷键通过统一入口处理，不因组件重新挂载而叠加监听器。
- 搜索支持上下方向键选择和回车打开，选中结果应滚动到可见区域；异步旧查询不能覆盖较新的关键词结果。
- 搜索与抽屉遵循模态焦点范围，背景不可交互；关闭恢复此前触发元素及必要的输入光标位置。原触发元素消失时恢复至合理的页面入口。Esc 优先关闭最上层浮层，再退出专注模式。
- 专注模式收起侧栏及首页次要区域，正文保持居中；保留明确退出方式。隐藏控件不能继续接收焦点。
- 深浅主题切换先锁定旧主题的计算样式，再在同一过渡窗口内改变颜色、边框、阴影和图标描边；不能出现文字或控件先闪变后过渡。
- Tab 焦点清晰可见，按钮有可读名称，图标为装饰时不重复朗读。加载、失败和保存状态通过适当的无障碍提示区域传达。

## 6. 交付检查

与基准同时对照浅色、深色和专注模式，在常用尺寸及最小窗口验证首页、列表、抽屉和搜索；使用长中文标题、多标签、长正文及代码块检查溢出。实际操作连续切页、中文选字、分类方向键、浮层焦点循环与恢复、搜索快速改词及减少动态设置。

草稿与保存流程还需验证重启恢复、保存失败保留、重复提交不重复创建、已有手记修改同步与搜索一致。视觉检查不能代替 SQLite 与桌面生命周期的实际验证。每项检查如实记录通过、失败或未运行，平台声明仅覆盖实际验证的平台。

搜索的模糊层、暗色遮罩与面板作为同级元素分别过渡；共同父层不设置透明度或滤镜，避免改变背景采样边界而在动画结束时突变。模糊层保持固定滤镜，通过透明度连续混合清晰与模糊背景。退出等待全部子层过渡完成，系统减少动态偏好开启时即时完成。
