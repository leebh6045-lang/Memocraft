# 标签自选与「已收录」标记交付 · 2026-09-24

## 交付内容

创建手记时的标签从"手打一行逗号"改成**右侧抽屉点选**；手记卡片上的标签变成独立胶囊，「收录于 X」换成同尺寸的蓝色「已收录」胶囊。手记详情里的标签编辑**保持原样**（只有逗号输入框）。

### 1. 选择标签抽屉

- 补充区的标签只剩一行：**已选胶囊 + `＋ 选择标签`**，标签以后加到多少个都不会变高。
- 点开右侧抽屉（复用 `SideDrawer`，与手记详情同一形态：320ms 右滑、遮罩淡入、焦点锁在抽屉内、`Esc` 关闭）。
- 15 个预设标签按四组排开，**点标签不关抽屉**（可连续多选），底部可加自定义标签（回车或逗号分隔），抽屉只在「完成」或 `Esc` 时收起。
- 已选胶囊带 `×`：删标签不必再打开抽屉；抽屉里也有一行「已选」，不用回头看编辑器。
- 半截输入不会丢：点「完成」时先把输入框里还没回车的文本并入再关闭。

### 2. 卡片上的标签与「已收录」

- 标签是**淡底药丸**（保留 `#` 前缀，`#` 是装饰、不进可读名称），和正文、时间一眼分开。
- 被收录过的手记在标签之后追加一枚**同尺寸的蓝色胶囊**：收录到一个归纳写「已收录」，多个写「已收录 · 2」；悬停提示与可读名称给出归纳名字（「已收录到：服务器运维、本地数据库」）。
- **卡片上不再出现「收录于 X」**；未被收录的手记不显示任何标记；归纳详情里的手记也不显示（那里每条都已经在这个归纳里）。

### 3. 预设标签表

四组 15 个，只按一根轴分（这条手记是什么），外加一组生活领域：

| 组         | 标签                               |
| ---------- | ---------------------------------- |
| 学到与想到 | 启发 · 涨知识 · 参考 · 灵感 · 疑惑 |
| 做法       | 方法流程 · 清单 · 改进             |
| 经历       | 踩坑 · 复盘 · 决定 · 突发事件      |
| 生活       | 生活 · 情绪 · 健康                 |

**标签在数据里始终只是字符串**：预设、自定义、详情里手写的三者完全等价，不新增表、不新增字段，导出与搜索不受影响。换分类只改 `src/renderer/src/tag-presets.ts` 这一张表，不动任何已存的手记。

## 期间修正的问题

1. **`#` 前缀跑进了可读名称**：最初用 CSS `::before` 画 `#`，浏览器会把生成内容算进按钮的可读名称，抽屉里的标签按钮读成「井号踩坑」。改成 `aria-hidden` 的实文本，视觉不变、可读名称就是标签本身。
2. **半截自定义标签会被丢掉**：输入后没有回车就点「完成」时，文本原本会丢。现在关闭前先并入。
3. **`desktop.spec.ts` 依赖已删除的标签输入框**：改为走抽屉的自定义标签分支（搜索里按 `sqlite` 命中仍然成立）。

## 未做
