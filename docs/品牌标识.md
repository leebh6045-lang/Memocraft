# Memocraft 品牌标识 V2

本文件是品牌标识当前方案与使用规则。界面颜色、圆角与尺寸令牌以
[界面与交互基准](界面与交互基准.md) 为准，本文不另立一套。

**当前状态：候选已产出，尚未接入应用。** `resources/brand/` 下的旧标识与
`electron-builder.yml`、`src/main/window.ts`、`src/renderer/index.html` 的引用都保持原样，
接入步骤见第 7 节。候选对比页见 `resources/brand/v2/preview.html`。

## 1. 为什么重做

旧标识是暖米色（`#D8C4A5`、`#F4E8D2`）加深藏青（`#202A44`）的折纸字母 M，
而界面实际使用的是冷灰蓝体系：纸色 `#f7f6f3`、强调色 `#3b5b7c`、深色强调 `#8fb0d6`。
两者是互不相干的两套语言——标识放进侧栏、放在浅色背景上都会显得偏黄、偏重。
V2 的目标是让标识只用界面已有的颜色，并且缩到 16px 仍能辨认。

## 2. 两个候选

| 候选          | 概念                                                         | 长处                                   | 短处                                   |
| ------------- | ------------------------------------------------------------ | -------------------------------------- | -------------------------------------- |
| 甲 · 三级层叠 | 三张纸卡自上而下逐层变宽变深，对应手记 → 归纳 → 事务三级沉淀 | 16px 下仍能读出层数；结构最能表达产品  | 三条横杠容易被读成列表或图表，通用感强 |
| 乙 · 折角纸页 | 一张纸页折起右下角，表示正在写的内容被折好收存               | 轮廓干净、不像通用图标；折角提供方向感 | 16px 下折角会糊，靠左上圆点维持识别    |

**推荐乙。** 依据是第 5 节的小尺寸实测：乙在 32px 与 64px 下的辨识度不输甲，
而甲的通用感在应用图标这种需要一眼记住的位置是实质扣分项。
两个候选的文件都保留在 `resources/brand/v2/`，甲随时可以并行推进。

## 3. 几何

所有标记共用 512 × 512 画布。坐标是绝对单位，改这里就能整体调整比例。

甲的层叠层：

| 层  | x   | y   | 宽  | 高  | 圆角 |
| --- | --- | --- | --- | --- | ---- |
| 上  | 158 | 96  | 196 | 92  | 30   |
| 中  | 124 | 208 | 264 | 92  | 30   |
| 下  | 90  | 320 | 332 | 92  | 30   |

- 三层左边缘对齐在 x = 90，形成阶梯状左轮廓；每层比上层宽 68、高 92，层间距 28。
- 整体高度 316，留白由画布四边均分，保证在正方形与圆形裁切下都不偏。

乙的纸页与折角：

| 元素 | 参数                                        |
| ---- | ------------------------------------------- |
| 纸页 | x = 96、y = 96、320 × 320、圆角 64          |
| 折角 | 边长 96，切在右下角，折面为斜边向内的三角形 |

- 折角尺度取纸页边长的 30%。再大，16px 下折角会吃掉整张纸；再小则看不出是折角。
- 折角三角形内缩 30 单位，使折面与纸页之间留出一条深色缝隙，避免两个形状粘成一块。

应用图标在标记之外还有两项固定处理：

- 底色圆角方，`rx = 112`（512 画布），填充 `#2f4a66`。
- 左上角一枚 `r = 24` 的 `#b8862b` 圆点。它的来源是界面里的分类标记色，
  作用是在折角糊成噪点时仍然提供识别锚点；不要为了“干净”删掉它。

## 4. 颜色

全部取自界面基准，没有新增色值：

| 用途                    | 色值                 | 来源                      |
| ----------------------- | -------------------- | ------------------------- |
| 浅色界面的标识主体      | `#2f4a66`            | 强调色 `#3b5b7c` 压低一档 |
| 浅色界面的次要层 / 折角 | `#8fb0d6`            | 深色主题强调色            |
| 三级层叠的最上层        | `#c9d8e8`            | 强调浅 `#e6edf5` 加深一档 |
| 深色界面上的主体        | `#f7f6f3`            | 浅色主题背景（纸色）      |
| 深色界面上的次要层      | `#7f9dc0`、`#20344a` | 折角与层叠的对照层        |
| 识别点                  | `#b8862b`            | 语义色「待办」            |

标记只用于浅色背景时可以用 `#3b5b7c` 原色；`#2f4a66` 是为了在小尺寸与低质量屏幕上
保持与纸色背景的对比度。不要在标识内部混用其他语义色（`#4f8a63`、`#b3473f`）。

## 5. 尺寸与最小尺寸

实测结论（`sips` 光栅化，非浏览器预览）：

| 尺寸 | 甲                   | 乙                   |
| ---- | -------------------- | -------------------- |
| 64px | 三层清晰             | 纸页与折角清晰       |
| 32px | 三层可辨             | 折角可辨             |
| 16px | 中间层与底色开始融合 | 折角糊掉，圆点仍可辨 |

- 应用图标最小 32px，低于此值改用 `favicon.svg`（32 画布专用绘制，放大内部形状）。
- 界面内标记最小 20px，使用 `mark-yi-fold-mono.svg` 的单色版本。
- 标记四周留白不少于自身边长的 25%。不要在标记外加描边、阴影或圆角底板。

## 6. 文件清单（`resources/brand/v2/`）

| 文件                                            | 用途                                                                       |
| ----------------------------------------------- | -------------------------------------------------------------------------- |
| `mark-yi-fold.svg`                              | 浅色界面标记                                                               |
| `mark-yi-fold-on-dark.svg`                      | 深色界面标记                                                               |
| `mark-yi-fold-mono.svg`                         | 单色标记，配 `currentColor` 场景                                           |
| `app-icon-yi-fold.svg`                          | 应用图标源文件（含深底与识别点）                                           |
| `favicon.svg`                                   | 16–32px 专用绘制                                                           |
| `lockup-yi-fold.svg`                            | 横排锁定：标记 + 英文名 + 「创忆工坊」                                     |
| `mark-jia-stack*.svg`、`app-icon-jia-stack.svg` | 候选甲的对应文件                                                           |
| `assets/`                                       | 位图产物：`app-icon-16…1024.png`、`favicon-16/32/180.png`、`app-icon.icns` |
| `preview.html`                                  | 候选对比页，双击用浏览器打开                                               |

SVG 与 `assets/` 下的位图都由脚本生成，不要手工编辑产物：
改几何后重新运行生成脚本即可覆盖，否则下次生成会把手工改动抹掉。

**生成方式：** 几何脚本在 `.local/brand-v2-render/build-assets.mjs`（本地原型目录，不提交）。
若要长期维护，应把脚本移入 `scripts/` 并纳入检查；当前先作为一次性产出说明其来源。

## 7. 接入步骤（尚未执行）

接入需要同时改四处，缺一处就会出现新旧混用：

1. `electron-builder.yml` 的 `icon:` 由 `resources/brand/memocraft-app-icon.png`
   改为 `resources/brand/v2/assets/app-icon.icns`（macOS 打包用 icns 才能带全尺寸）。
2. `src/main/window.ts` 里窗口图标路径 `resources/brand/memocraft-app-icon.png`
   改为 `resources/brand/v2/assets/app-icon-512.png`。
3. `src/renderer/index.html` 的 favicon 指向 `/src/assets/memocraft-mark.svg`，
   需替换 `src/renderer/src/assets/memocraft-mark.svg` 的内容（或改指向新文件）。
4. `src/renderer/src/App.vue` 引用的 `./assets/memocraft-mark.svg` 同步替换。

`electron-builder.yml` 的 `extraResources` 会把整个 `resources/brand` 复制进包内，
因此第 2 步的路径在打包后是 `<Resources>/brand/v2/assets/app-icon-512.png`，
开发环境与打包环境都要验证。

## 8. 不要这样做

- 不要拉伸、旋转或改变标记的长宽比；需要竖排时重排元素，不做形变。
- 不要把标记放进再套一层圆角底板的容器里——应用图标已经自带底色。
- 不要在标记上叠加渐变、投影或模糊；界面基准里浮层才用阴影。
- 不要用旧标识的暖米色做“过渡配色”，那正是本次要消除的不一致。
