# 版本发布文档

本目录存放版本里程碑和阶段交付总结文档。

## 目录结构

- `v1/` - 首轮开发的阶段交付文档
- `v1.5/` - v1.5 版本的交付总结
- `v2/` - v2 版本的规划与实施文档

## 文档类型

### 阶段交付
记录某个开发阶段完成的所有功能和关键变更，通常包含：
- 本阶段完成的功能列表
- 关键技术变更
- 验证结果
- 遗留问题

### 版本交付
记录某个发布版本的整体交付内容，通常包含：
- 新增功能总览
- 破坏性变更
- 升级说明
- 已知问题

## 命名规范

```
{YYYY-MM}-阶段X交付.md
{YYYY-MM}-vX.X交付.md
```

## 与功能文档的关系

版本文档是横向的里程碑总结，功能文档是纵向的功能实现记录。

- 想了解"某个版本做了什么" → 查看 releases/
- 想了解"某个功能怎么实现的" → 查看 features/
