# 详情页改版交付 · 归纳与事务的基础信息收进右侧抽屉 · 2026-09-24

## 改版原因

用户对照实物提出的三点要求：

1. 归纳与事务的基础信息填写不该占页面顶部，应与手记一致，从右侧抽屉唤出；唤出入口是「事务详情／归纳详情」性质的按钮。
2. 事务的动态时间线应放在基础信息原来的位置（标题下方），因为事务本身就是关于动态的；记录动态同样改为「记录」按钮唤出右侧抽屉。
3. 从长期事务列表进入单个事务的过渡仍是旧效果，应与进入归纳一致。

原型（`.local/prototypes/11-detail-refactor.html`）先做静态实现并经用户确认「按这个做，这就是我想要的效果」，随后落到 `src/`。原型阶段另确认三件事：说明与概况**全部**收进抽屉；删除入口**只**放在编辑抽屉底部；直接关联的手记**留在**时间线下方。

## 本轮成果

- **详情页顶部只读**：事务详情顶部为标题 + 状态胶囊，右上角只留「编辑基础信息」与「归档／重新启用」；归纳详情为标题 + 「编辑基础信息」「收录已有手记」。标题通过共享元素过渡从卡片位置连续移动过来，事务与归纳走同一条路径。
- **基础信息进抽屉**：标题、说明（事务另含「当前概况」）在右侧 `编辑基础信息` 抽屉里编辑，仍是改动即自动保存，抽屉内有「已保存／保存失败」状态行；删除入口（移到回收站）只出现在抽屉底部。
- **记录动态进抽屉**：`＋ 记录动态` 唤出 `记录动态` 抽屉，含动态描述（必填）、发生时间、标签、详细内容与引用手记；提交后抽屉关闭、时间线更新并提示「已记录动态」。
- **时间线上移**：`动态 N`、正倒序切换与 `＋ 记录动态` 紧跟标题，直接关联的手记留在时间线下方不动。
- **抽屉形态统一**：新增 `SideDrawer`（容器：挂在 body、遮罩 + 面板、进出场动效）与 `SideDrawerPanel`（面板本体：焦点接管、Esc 让位、模态层计数），与手记抽屉共用 320ms 右滑进入、遮罩淡入淡出与焦点回退规则。

## 结构变更与踩到的坑

页面的根节点必须保持**单元素**。抽屉最初写成 `<Transition><SideDrawer v-if=… /></Transition>` 直接挂在页面根下，两个后果同时出现：

1. `SideDrawer` 根是 `<Teleport>`，Vue 会把过渡钩子挂到 Teleport 内部**第一个非注释子节点**上，于是样式落到遮罩而不是面板，滑动动画失效；
2. 两个 `<Transition>` 让页面组件变成多根片段，应用外壳 `<Transition mode="out-in">` 的离场钩子再也拿不到元素，**页面切换后主区域空白**——`main` 里只剩一个注释节点。

现在抽屉的遮罩与面板同属一个 `.drawer-layer`（固定的公共父层），过渡挂在它上面；抽屉改用 `:open` 属性而不是 `v-if` 挂在页面上，面板随 `open` 挂载，因此关闭时也有退场动画；两条 `<SideDrawer>` 都移进页面根 `<section class="view">` 内。

## 关键文件

- `src/renderer/src/components/SideDrawer.vue`（新增）：Teleport 到 body 的抽屉容器，`.drawer-layer` + 过渡。
- `src/renderer/src/components/SideDrawerPanel.vue`（新增）：`role="dialog"` 面板，复用 `useModalFocus` 与 `useModalLayer`。
- `src/renderer/src/pages/ThreadsPage.vue`、`src/renderer/src/pages/TopicsPage.vue`：只读详情头、时间线上移、两个抽屉、`:open` 绑定。
- `src/renderer/src/components/EntryFields.vue`：摘要行在「记录动态」抽屉里由描述字段承担，`summary` 变为可选并在 `show-summary="false"` 时隐藏。
- `src/renderer/src/assets/theme.css`：`.detail-head`／`.detail-title`／`.drawer-layer`／抽屉标题行样式。
- `docs/界面与交互基准.md`：第 2、3、5 节同步为「顶部只读 + 抽屉编辑 + 时间线紧随标题」。
