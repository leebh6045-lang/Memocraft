# 归纳列表视觉强化方案

> 背景：知识归纳页面卡片数量增多后，每张卡片外观完全一致，用户无法快速判断哪个归纳投入最多、最活跃。本文档给出四个独立可选方案，每个方案均包含完整的改动位置、逻辑描述和 CSS/模板细节，供实现模型直接对照执行。
>
> 涉及文件：`src/renderer/src/pages/TopicsPage.vue`（全部改动集中于此文件，除非方案 D 注明需改 computed）

---

## 通用前置说明

### 现有数据与 CSS 变量

`TopicSummary`（来自 `src/domain/topic.ts`）已有字段：

| 字段 | 类型 | 用途 |
|------|------|------|
| `noteIds` | `string[]` | 收录手记数量的直接来源 |
| `createdAt` | `string` (ISO) | 创建时间，已在卡片展示 |
| `updatedAt` | `string` (ISO) | 最近更新时间，**当前未在卡片展示** |
| `title` | `string` | 标题 |
| `description` | `string` | 说明文字 |

`Note`（来自 `src/domain/note.ts`）已有字段中 `category` 会映射到 CSS 类 `cat-${note.category}`，目录视图已在用（`toc-dot` 色点）。

页面已使用的 CSS 变量（来自全局主题，直接引用即可）：

```

--border         边框色
--border-strong  较深边框
--surface        卡片底色
--surface-2      悬停/高亮底色
--faint          极淡文字（次要信息）
--muted          淡文字（辅助信息）
--text           正文色
--radius-s       小圆角
--dur-1          短动效时长
--dur-2          中动效时长
--ease           标准缓动
```

## 方案 A：相对填充条

### 效果描述

每张卡片底部有一条细横线，宽度按照「该归纳手记数 ÷ 所有归纳中最多手记数」比例填充。0 条的卡片是一条很短的线（或完全不显示），13 条的卡片几乎铺满底部。颜色用 `--accent` 加低透明度，不过分抢眼。

### 改动位置

#### 1. 新增 computed：最大手记数

在 `<script setup>` 中，找到现有的 `tocEntries` computed（约第 126 行），在其**后面**紧接着新增：

```typescript
/** 所有归纳中手记最多的数量，用于计算填充条比例；列表为空时返回 1 避免除零。 */
const maxNoteCount = computed(() =>
  topics.value.reduce((max, t) => Math.max(max, t.noteIds.length), 1),
);
```

#### 2. 修改卡片模板

找到 `<div v-else class="grid">` 下的卡片模板（约第 399–414 行）：

```html
<!-- 当前 -->
<button
  v-for="(topic, index) in topics"
  :key="topic.id"
  class="card collection"
  @click="showDetail(topic.id)"
>
  <span class="index">{{ String(index + 1).padStart(2, '0') }}</span>
  <h3 :style="{ viewTransitionName: `topic-${topic.id}` }">{{ topic.title }}</h3>
  <p>{{ topic.description || '还没有说明' }}</p>
  <span class="meta-line"
    ><span>{{ topic.noteIds.length }} 条手记</span
    ><span>{{ formatTime(topic.createdAt) }} 创建</span></span
  >
</button>
```

替换为：

```html
<button
  v-for="(topic, index) in topics"
  :key="topic.id"
  class="card collection"
  @click="showDetail(topic.id)"
>
  <span class="index">{{ String(index + 1).padStart(2, '0') }}</span>
  <h3 :style="{ viewTransitionName: `topic-${topic.id}` }">{{ topic.title }}</h3>
  <p>{{ topic.description || '还没有说明' }}</p>
  <span class="meta-line"
    ><span>{{ topic.noteIds.length }} 条手记</span
    ><span>{{ formatTime(topic.createdAt) }} 创建</span></span

    class="fill-bar"

```

#### 3. 新增 CSS

在 `<style scoped>` 末尾追加：

```css

.fill-bar {
  display: block;
  position: absolute;
  bottom: 0;
  left: 0;
  height: 3px;
  width: calc(var(--fill-ratio, 0) * 100%);
  background: var(--accent);
  opacity: 0.35;
  border-radius: 0 0 var(--radius-s) var(--radius-s);

/* 卡片需要 position: relative 才能让填充条定位正确 */

  position: relative;
  overflow: hidden; /* 防止填充条在圆角外溢出 */
}
```

## 方案 B：手记数字号强化

### 效果描述

把「N 条手记」从底部 meta 行中提取出来，单独变成一个视觉分量明显的大数字放在卡片左下角（或右上角）。字号大（约 28–32px）、字重轻（300），像杂志数据卡片风格。0 条用 `--faint` 色淡化，10 条以上数字一眼显眼。「条手记」文字维持小字紧跟在数字右下。

## 方案 C：最后活跃时间 + 列表排序

### 效果描述

两个独立子功能，可以分开实现，但组合效果最好：

1. **卡片增加「最近收录」时间**：展示 `topic.updatedAt`，让用户看到哪个归纳最近还在增长。
2. **列表顶部增加排序控件**：新增「手记最多」和「最近更新」两种排序，默认保持「创建时间」（即现有顺序）。排序选择持久化到 localStorage。

### 改动位置

#### 1. 新增排序偏好（view-preferences.ts）

打开 `src/renderer/src/view-preferences.ts`，在文件末尾追加：

```typescript
export type TopicsSort = 'created' | 'count' | 'updated';

export const TOPICS_SORTS: { value: TopicsSort; label: string }[] = [
  { value: 'created', label: '创建时间' },
  { value: 'count', label: '手记最多' },
  { value: 'updated', label: '最近更新' },
];

const TOPICS_SORT_KEY = 'topics-sort';

export function readTopicsSort(): TopicsSort {
  const raw = localStorage.getItem(TOPICS_SORT_KEY);
  if (raw === 'count' || raw === 'updated') return raw;
  return 'created';
}

export function writeTopicsSort(value: TopicsSort): boolean {
  try {
    localStorage.setItem(TOPICS_SORT_KEY, value);
    return true;
  } catch {
    return false;
  }
}
```

#### 2. 在 TopicsPage.vue 的 script 中引入并使用

在 `<script setup>` 顶部的 import 中，追加新导出项：

```typescript
import {
  // ... 已有导入保持不变 ...
  TOPICS_SORTS,
  readTopicsSort,
  writeTopicsSort,
  type TopicsSort,
} from '../view-preferences';
```

在 `layout` ref 定义（约第 86 行）附近，新增排序相关状态和 computed：

```typescript
const sort = ref<TopicsSort>(readTopicsSort());

function chooseSort(value: TopicsSort): void {
  if (sort.value === value) return;
  sort.value = value;
  if (!writeTopicsSort(value)) {
    emit('notify', { message: '已切换排序，但偏好未能保存，重启后会回到创建时间。' });
  }
}

/** 按当前排序方式排列的归纳列表；原始 topics 为创建时间倒序，直接使用即为 'created'。 */
const sortedTopics = computed(() => {
  if (sort.value === 'count') {
    return [...topics.value].sort((a, b) => b.noteIds.length - a.noteIds.length);
  }
  if (sort.value === 'updated') {
    return [...topics.value].sort(
      (a, b) => new Date(b.updatedAt).getTime() - new Date(a.updatedAt).getTime(),
    );
  }
  return topics.value; // 'created'：保持原始顺序
});
```

#### 3. 修改模板：header 区域增加排序控件

找到 `<div class="actions">` 内现有的 `seg seg-sm` 布局切换控件，在其**前面**新增排序控件（两个控件组并排）：

```html
<div class="actions">
  <div v-if="topics.length" class="seg seg-sm" role="radiogroup" aria-label="排序方式">
    <button
      v-for="option in TOPICS_SORTS"
      :key="option.value"
      type="button"
      role="radio"
      :aria-checked="sort === option.value"
      @click="chooseSort(option.value)"
    >
      {{ option.label }}
    </button>
  </div>
  <div v-if="topics.length" class="seg seg-sm" role="radiogroup" aria-label="排列方式">
    <!-- 已有布局切换按钮保持不变 -->
  </div>
  <button class="btn-primary" :disabled="props.busy" @click="openCreate">
    <span aria-hidden="true">＋</span> 新建归纳
  </button>
</div>
```

#### 4. 修改模板：卡片列表改用 sortedTopics

将网格和目录视图中的 `v-for="(topic, index) in topics"` 全部改为 `v-for="(topic, index) in sortedTopics"`。

目录视图同理：`tocEntries` computed 当前基于 `topics.value`，将其改为基于 `sortedTopics.value`：

```typescript
// 原来
const tocEntries = computed(() =>
  topics.value.map((topic) => { ... }),
);

// 改为
const tocEntries = computed(() =>
  sortedTopics.value.map((topic) => { ... }),
);
```

#### 5. 修改卡片模板：增加 updatedAt

在 `meta-line` 中，将原来的单行时间改为两行或增加「最近收录」：

```html
<span class="meta-line">
  <span>{{ topic.noteIds.length }} 条手记</span>
  <span>{{ formatTime(topic.createdAt) }} 创建</span>
</span>
<span v-if="topic.noteIds.length > 0" class="meta-updated">
  最近收录 {{ formatTime(topic.updatedAt) }}
</span>
```

#### 6. 新增 CSS

## 方案 D：类别色点迷你分布

### 效果描述

在每张卡片内，用 3–5 个小色点（直径 5–6px）展示收录手记的类别分布。色点颜色复用目录视图已有的 `cat-${category}` CSS 类。多个同类别的手记合并成一个较大的色点（直径随数量略有放大，上限到 9px），或者改为显示最多 N 个点（超出部分不显示）。

这让每张卡片在视觉上「各有性格」——一个全是笔记类的归纳色点均匀，一个混合了想法和问题的归纳色点多样。

### 改动位置

#### 1. 新增 computed：每个归纳的类别分布

在 `<script setup>` 中，在 `maxNoteCount` 附近（或任意合适位置）新增：

```typescript
/**
 * 每个归纳收录手记的类别分布，用于色点展示。
 * 返回 Map<topicId, { category: string; count: number }[]>，按数量倒序。
 */
const topicCategoryDist = computed(() => {
  const result = new Map<string, { category: string; count: number }[]>();
  const noteById = new Map(props.notes.map((n) => [n.id, n]));
  for (const topic of topics.value) {
    const counts = new Map<string, number>();
    for (const id of topic.noteIds) {
      const note = noteById.get(id);
      if (note) counts.set(note.category, (counts.get(note.category) ?? 0) + 1);
    }
    const dist = [...counts.entries()]
      .map(([category, count]) => ({ category, count }))
      .sort((a, b) => b.count - a.count);
    result.set(topic.id, dist);
  }
  return result;
});
```

#### 2. 修改卡片模板

在卡片内的 `meta-line` 之前插入色点行：

```html
<button
  v-for="(topic, index) in topics"
  :key="topic.id"
  class="card collection"
  @click="showDetail(topic.id)"
>
  <span class="index">{{ String(index + 1).padStart(2, '0') }}</span>
  <h3 :style="{ viewTransitionName: `topic-${topic.id}` }">{{ topic.title }}</h3>
  <p>{{ topic.description || '还没有说明' }}</p>
  <!-- 类别色点：最多展示 5 个类别 -->
  <span
    v-if="topic.noteIds.length > 0"
    class="cat-dots"
    :aria-label="`收录手记类别：${topicCategoryDist.get(topic.id)?.map(d => d.category).join('、')}`"
  >
    <span
      v-for="dist in (topicCategoryDist.get(topic.id) ?? []).slice(0, 5)"
      :key="dist.category"
      class="cat-dot"
      :class="`cat-${dist.category}`"
      :style="{ '--dot-count': dist.count }"
      aria-hidden="true"
    />
  </span>
  <span class="meta-line"
    ><span>{{ topic.noteIds.length }} 条手记</span
    ><span>{{ formatTime(topic.createdAt) }} 创建</span></span
  >
</button>
```

#### 3. 新增 CSS

```css
/* 方案 D：类别色点迷你分布 */
.cat-dots {
  display: flex;
  align-items: center;
  gap: 4px;
  margin-bottom: 8px;
}
.cat-dot {
  flex: none;
  /*
   * 色点大小随该类别手记数量略有放大：
   * count=1 → 5px, count=5 → 7px, count>=10 → 9px，用 clamp 平滑过渡。
   * --dot-count 由模板内联传入。
   */
  --size: clamp(5px, calc(4px + var(--dot-count, 1) * 0.4px), 9px);
  width: var(--size);
  height: var(--size);
  border-radius: 50%;
  /*
   * 颜色沿用 cat-${category} 的 --cat-color 变量，与目录视图保持一致。
   * 若全局样式里 .cat-* 只设置了 background 而非 --cat-color，则改为 background: var(--cat-color)
   * 或直接保留 cat-${category} 的 background 规则（两者兼容）。
   */
  background: var(--cat-color, var(--faint));
  opacity: 0.85;
}
```

> 重要提示：`cat-${category}` CSS 类在目录视图（`.toc-dot`）中已经使用，但该类的实际颜色变量名（是 `--cat-color` 还是直接写的 `background`）需要检查 `src/renderer/src/assets/` 或全局样式文件，确保 `.cat-dot` 能正确继承颜色。如果全局样式用 `background` 而非 CSS 变量，则 `.cat-dot` 的 `background` 规则会被全局规则覆盖，可以将 `.cat-dot` 改为不设置 `background`，让全局的 `.cat-*` 规则直接生效。

## 四方案对比表

| | 改动范围 | 新数据 | 纯 CSS | 主要收益 |
|---|---|---|---|---|
| A 填充条 | 模板 + CSS + 1 computed | 否 | 大部分 | 一眼扫出分量差异 |
| B 数字强化 | 模板 + CSS | 否 | 是 | 数字本身有了视觉分量 |
| C 排序+活跃 | 模板 + CSS + view-preferences.ts | updatedAt（已有）| 小部分 | 功能性最强，直接解决排序需求 |
| D 色点分布 | 模板 + CSS + 1 computed | category（已有）| 大部分 | 每张卡片有差异感，信息最丰富 |

推荐组合实现顺序：**C（排序）→ A（填充条）→ D（色点）→ B（数字强化）**，根据实际效果取舍。
