# 主页面分层入场设计

## 显示交接

保留既有内容就绪、首帧与卡片 500 毫秒条件。主界面挂载前准备入场状态并订阅有限的 `memocraftWindow.onPresented(listener)`，隐藏准备期间只预置透明状态，不启动动画。

主进程销毁卡片，显示并聚焦主窗口后发送 `window:presented(true)`。渲染器在下一绘制帧启动分层动画，订阅只消费一次，不等待动画完成才启用编辑器。普通浏览器无生命周期桥接时正常显示。

主窗口重新加载后发送的内容就绪通知只收到 `false`，释放预备状态而不再播放。因此启动协调器交接后保留主窗口就绪通知与关闭清理，展示计时器、卡片和首帧监听仍在交接时释放；窗口关闭或确认退出时解除剩余通知。恢复、激活及第二实例只显示窗口，不发送新的入场通知。

## 分层参数

使用浏览器原生 Web Animations API，只改透明度与变换，不改变布局高度；不引入动画依赖。通过显式 `data-startup-part` 标记当前页面节点，播放时抓取一份快照，后来新增的手记不会加入启动队列。

| 部分                        | 时长 / 延迟       | 起始状态        |
| --------------------------- | ----------------- | --------------- |
| 应用内容与左下角入口        | 100ms / 0ms       | 透明            |
| 侧栏                        | 230ms / 0ms       | 透明、左移 22px |
| 首页标题或明确的加载错误页  | 240ms / 35ms      | 透明、下移 16px |
| 编辑区                      | 260ms / 60ms      | 透明、下移 24px |
| 草稿状态与创建归纳/事务入口 | 180ms / 110ms     | 透明、下移 12px |
| 最近手记标题、空状态        | 200ms / 125ms     | 透明、下移 16px |
| 最多四条最近手记            | 210ms / 125–150ms | 透明、下移 22px |

缓动沿用定稿 `cubic-bezier(.22,.61,.36,1)`。最近手记仅前两档延迟，保证已有四条时仍不超过 360 毫秒；标题栏与原生窗框保持稳定。动画不覆盖普通切页或列表重排规则。

## 取消与恢复

所有动画结束后移除启动标记并取消填充效果，恢复元素本来样式；用户首次键盘、指针操作时立即完成视觉交接。系统减少动态、偏好在播放中变化、页面离开或组件卸载均清理帧回调、动画与监听。动画能力不可用或创建失败时立即恢复可见页面，不能妨碍编辑。

## 验证计划

针对主进程测试初次通知发生在卡片销毁和原生显示之后、恢复不重发、重新加载回复不播放，以及监听最终释放。渲染器测试仅一次播放、交互取消、减少动态和异常可见退路。真实 Electron 观察隐藏准备、分层中间态及结束状态，验证主题、草稿恢复、窗口召回与重新加载；打包后重复受影响流程。
