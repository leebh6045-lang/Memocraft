# 主页面分层入场交付

## 用户可见变化

独立启动卡片保持原有 0.5 秒节奏。卡片消失、主窗口显示后，侧栏从左侧进入，首页标题与编辑区依次上移淡入，草稿状态、创建入口与最近手记随后出现，整段约 360 毫秒。浅色和深色使用同样的入场节奏，标题栏与布局保持稳定。

动画在真实窗口显示后才开始，不会在卡片后方提前播放。用户开始键盘或指针操作时，剩余装饰立即结束，输入及保存不等待动画完成。减少动态时直接呈现完整界面。

入场仅在进程首次启动播放。最小化恢复、系统激活、第二实例唤回、切页、切主题与页面重载均不重播；重载仍恢复草稿，未留下透明控件。

## 关键实现

- `startup-window.ts` 在销毁卡片、显示并聚焦原生主窗口后发送 `window:presented(true)`；完成交接后只保留应答页面重载所需的就绪通知，重载回复 `false`，窗口关闭或确认退出后解除。
- shared/preload 为现有最小生命周期桥接增加类型明确的 `onPresented` 订阅；不增加业务能力，不改变内容就绪来源检查。
- `startup-entrance.ts` 在 Vue 挂载前订阅通知并设置预备状态，下一绘制帧才使用 Web Animations API；`startup-entrance.css` 仅负责隐藏准备期间的初始透明度。
- `App.vue` 与 `HomePage.vue` 以 `data-startup-part` 标记动画节点。播放时抓取当前节点，不让后来新增手记重新进入启动队列；最近四条只采用两档延迟，总时长上限 360 毫秒。
- 空草稿的隐藏状态提示不参与入场，避免装饰圆点闪现。动画结束、首次交互、减少动态切换、页面离开或组件卸载统一清理；动画创建失败立即恢复可见页面，不写入永久内联变换。
- 产品规格、界面基准、项目结构、启动卡片设计及协作导航已同步。

本轮不增加依赖、设置项、数据库迁移或数据副本，不包含原型的慢放、定格和循环播放功能。

## 验证边界

- 实测平台为 macOS arm64，未验证 Windows、Intel Mac 或 Linux，也未签名、公证或发布。
- 全仓格式问题仍是三份 `docs/.templates/` 模板、`docs/features/packaging/2026-10-Windows安装包卸载选项-交付.md`、`docs/releases/README.md`、`docs/review-effects-demo.html` 与 `docs/review-page-demo.html`。本轮定向格式检查单独记录，不宣称全仓全绿。
- 上一轮记录的设置侧栏按钮旧断言问题见[启动卡片交付](./2026-10-启动卡片-交付.md)，本轮没有修改或放宽该断言，也未重跑该无关用例。
- 动画只负责视觉效果，草稿恢复和错误处理仍由既有业务流程决定。用户提前交互或启用减少动态会使装饰提前结束，属于预期行为。
