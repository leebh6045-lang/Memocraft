# 模块命名交付

## 用户可见名称

主导航依次为「首页、手记、主题归纳、长期事务」，文本长度为 2、2、4、4 个字。主题归纳用于围绕主题收录相关手记，涵盖学习、工作、生活与个人思考。

同步更新模块导航、列表标题、归纳详情返回入口、保存及关联结果提示、设置中的项目简介，以及帮助网站的教程与交互演示。归纳仍作为业务实体简称使用，「新建归纳」「收录到归纳」等操作名称继续沿用。

## 项目内一致性

当前规范、项目说明、功能文档、演示稿、相关注释与已有测试统一使用当前模块名称。两份含旧模块名的文档改名为 `阶段1设计-主题归纳.md`、`手记呈现与归纳目录交付.md`，同步更新路径引用。

「随手记点什么……」「随手记录」及「随手记变化」等普通表达保留。已发布 SQL 迁移保留原文，不修改历史迁移注释或用户保存的内容。

两字模块名可能与业务按钮重合，桌面测试改为在「主导航」范围内定位手记入口。

## 验证

- Node 24.16.0、pnpm 11.4.0、Electron 44.4.3（macOS）。
- `pnpm typecheck`、`pnpm typecheck:plain`、`pnpm lint`、`pnpm build` 和 `git diff --check` 通过。
- 7 个相关单元与集成测试文件共 75 项通过，覆盖应用导航、草稿保存、手记时间分段、归纳阅读、设置及归纳和回收站存储。
- 5 项真实桌面验收通过：手记草稿重启与保存、写入失败后保留输入、新建归纳与多重收录及移出、呈现方式切换与重启保持、删除影响提示及恢复。首次在沙箱内启动 Electron 被终止，随后在沙箱外使用临时隔离数据目录执行通过。
- 核对桌面验收生成的 1000 × 700 深色截图，四个导航名称完整显示，文本长度保持 2、2、4、4 的排列。
- 本次涉及的源码、测试、正式文档及帮助网站通过定向 Prettier 检查；原演示稿仅替换两处模块名称，保留原格式。

- 扫描确认当前源码、测试、文档与帮助网站中没有旧归纳模块名称；旧手记模块名称仅在普通动词、介词表达中出现。重命名文档及原引用路径已核对，历史迁移按项目规范保留原文。
