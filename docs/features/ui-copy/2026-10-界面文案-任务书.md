# 界面文案任务书

落实已确认的精简版方案。首页标题改为「新建手记」，引导为「先写下来，其他慢慢补。」；收获输入提示保持原来的「现在想到什么……」，其他四类使用方案中的对应提示。

## 范围与验收

- 首页五类提示随当前分类变化；切换、清空正文及重启恢复时使用当前分类，正文、标题、标签、图片及草稿身份不因提示变化而丢失。
- 落实第二版的短句、AI 配置标题，以及延续的准确性修正：AI 检索及接收方、关系选择器、回顾计数、备份反馈、加载失败。
- 菜单、分类名、保存状态、必要的费用与数据保护说明保留；关于页沿用当前内容。
- 类型、lint、格式与相关自动化检查通过；隔离桌面知识库检查真实分类切换、草稿恢复和最小窗口深浅主题，不使用日常数据。

不扩展分类、存储模式、AI 功能或关于页，不实现新的发布或安装流程。
