# Memocraft 界面文案方案 · 第二版

这版优先用短句和日常说法。重点是五个分类的输入提示，其余只调整确实生硬的文案。关于页沿用现有的「项目简介」「作者想说的话」和作者落款。

用户已确认本版，并补充首页标题与收获提示的最终文字；本轮按本版实施。分类以当前的「收获、思绪、待办、完成、其他」为准。

## 1. 分类输入提示

推荐首页正文输入框使用这一组提示：

| 分类 | 推荐提示               | 引导方向                 |
| ---- | ---------------------- | ------------------------ |
| 收获 | **现在想到什么……**     | 灵感、发现与学到的东西   |
| 思绪 | **此刻的心情或想法……** | 感受、念头与个人思考     |
| 待办 | **接下来想做什么……**   | 打算做、需要处理的事     |
| 完成 | **记下一件做完的事……** | 已经做完的事，也可以补记 |
| 其他 | **随手记点什么……**     | 零散内容与备忘           |

收获按最终确认保持原来的「现在想到什么……」。首页标题由「新手记」改为「新建手记」，省略号统一用「……」。

思绪同时容纳心情和思考，不要求写成日记。待办、完成不限定“今天”或“刚刚”，也不催促完成。每个提示只给一个起笔方向，不规定用户必须写什么。

## 2. 分类切换时的表现

- 点击首页编辑器里的分类，输入框提示随所选分类变化。
- 已经写了正文时，内容照常保留；提示只在输入框为空时可见。
- 切换分类不清空标题、标签或图片，也不另开一份草稿。
- 恢复草稿时，使用草稿原有分类的提示；全新草稿默认收获。
- 每个分类固定一句，保持现有焦点和键盘操作，不轮播、不自动插入文字。
- 手记列表里的分类按钮继续只做筛选，不改变首页草稿。

首页上方的引导只保留一句：**「先写下来，其他慢慢补。」** 与输入框里的分类提示配合，不再反复解释可以记录哪些内容。

本轮方案优先针对首页正文。已有手记详情继续保留当前编辑方式；以后若要为其空正文增加提示，可以复用这组文字。

## 3. 其他文案的精简建议

| 位置           | 当前文案                                                         | 第二版建议                           |
| -------------- | ---------------------------------------------------------------- | ------------------------------------ |
| 首页引导       | 只需写下正文，其他都可以稍后补。                                 | **先写下来，其他慢慢补。**           |
| 手记说明       | 全部有效手记，按创建时间倒序。                                   | **最近写下的手记排在前面。**         |
| 归纳列表空状态 | 还没有归纳。                                                     | **建个归纳，把相关手记放在一起。**   |
| 新建归纳提示   | 标题必填，说明可以稍后补。允许同名，重命名不会重写已收录的关系。 | **先起个名字，说明以后再补。**       |
| 新建事务提示   | 标题必填，说明与当前概况可以稍后补。允许同名，稳定 ID 才是标识。 | **给这件事起个名字，其他以后补。**   |
| 事务参考资料   | 整个事务的参考资料放这里，不必为它虚构一条动态。                 | **关联手记，方便以后查找。**         |
| 当前概况说明   | 由你维护；动态只记录历史，不会自动改写它。                       | **需要时更新，动态不会改动这里。**   |
| 标签未选择     | 还没有选标签，下面点一下即可。                                   | **选几个标签，也可以先跳过。**       |
| 标签抽屉底部   | 已选 N 个 · 预设与自定义标签等价                                 | **已选 N 个 · 也可以自己加标签**     |
| AI 建议过期    | 正文或图片已修改，建议可能不再匹配。                             | **内容改了，建议可能不再适用。**     |
| 回顾空状态     | 这段时间没有新手记。                                             | **这段时间还没有手记，换一段看看。** |
| 回顾未接入 AI  | 请先在设置页配置 DeepSeek API Key，才能生成回顾。                | **先去设置里接入 AI。**              |

新建归纳和事务的标题字段同步标明「标题（必填）」，说明及当前概况继续标明可选。同名沿用现有提示，不新增填写步骤。

AI 内容区标题仍可使用 **「为 Memocraft 接入 AI」**；仅在未配置密钥时显示。已有密钥或配置状态未知时使用简短的 **「AI 服务」**，菜单也保留「AI 服务」。密钥已保存与连接测试成功继续分别表达。

每句只承担一个作用。页面已有“新建”“重新生成”等按钮时，说明句不必再重复一遍操作。

## 4. 准确性修正也尽量说短

上一版指出的准确性问题继续保留，常见场景可采用以下文字：

| 场景             | 建议文字                             | 必须保留的含义                                              |
| ---------------- | ------------------------------------ | ----------------------------------------------------------- |
| AI 检索无命中    | **这次没找到相关手记，换个词试试。** | 没找到不等于用户从未记录。                                  |
| 回顾计数         | **生成时有 N 条手记**                | N 是生成时的本期总数，回顾依据摘录生成。                    |
| 缺少本机备份记录 | **暂无备份记录。**                   | 不断言用户从未备份。                                        |
| 备份完成         | **备份已完成，包含 N 个图片附件。**  | 备份包含知识库；零图片也有完整备份。                        |
| AI 数据接收方    | **已保存的 AI 服务地址**             | 替换固定的“发送给 DeepSeek”，继续保留文字和图片的发送范围。 |

归纳用“收录”、事务资料用“关联”、动态用“引用”。加载失败与保存失败分别提示；只有实际保留输入的路径，才能说“输入仍在”。对应场景和调用链见[第一版的准确性清单](./2026-10-界面文案-方案.md#2-优先修正容易造成误解的文案)。

费用、密钥保护、备份与导出的区别、恢复替换范围、不能取消等必要说明继续保留完整信息。

## 5. 保留的内容与验收

以下沿用当前文案：

- 五个分类名称，以及首页、手记、主题归纳、长期事务等导航名称。
- 「保存手记」「添加图片」「新建归纳」「记录动态」「取消」「重试」等按钮。
- 「正在保存草稿…」「草稿已保存」「已保存到手记」等状态。
- 「正文还是空的，写点什么再保存。」和首页最近手记的现有空状态。
- 「正在阅读这条手记…」「正在从你的手记中查找…」等已有自然表达。
- 关于页的现有简介、作者寄语与「—— Ly」落款。

实施后重点检查：五类空正文分别显示对应提示；已有正文切换分类不丢内容；重启恢复原分类及提示；清空正文后出现当前分类的提示；列表筛选不影响草稿。另在浅深主题与 1000 × 700 最小窗口检查提示和标题是否完整可读。

实施与验证结果见[交付文档](./2026-10-界面文案-交付.md)。
