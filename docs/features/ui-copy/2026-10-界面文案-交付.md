# 界面文案交付

落实已确认的第二版方案及最终修正：首页标题改为「新建手记」，引导为「先写下来，其他慢慢补。」；收获提示保持原来的「现在想到什么……」。

| 分类 | 正文输入提示       |
| ---- | ------------------ |
| 收获 | 现在想到什么……     |
| 思绪 | 此刻的心情或想法…… |
| 待办 | 接下来想做什么……   |
| 完成 | 记下一件做完的事…… |
| 其他 | 随手记点什么……     |

提示由草稿当前分类派生，只作为 placeholder，不进入正文，不清空其他字段或另开草稿。恢复草稿沿用其分类，列表筛选与首页草稿继续隔离。

## 实现内容

- [首页](../../../src/renderer/src/pages/HomePage.vue) 增加分类提示，更新标题、引导与标签抽屉的默认来处说明；已有手记详情保持原编辑方式。
- 手记、归纳创建与空状态、事务创建与参考资料、当前概况、标签选择、回顾空状态及 AI 引导使用确认的短句。新建归纳和事务的标题字段明确标为必填。
- [AI 设置](../../../src/renderer/src/components/AiSettingsPanel.vue) 在无密钥时显示「为 Memocraft 接入 AI」，已有密钥或状态未知时显示「AI 服务」；不把密钥保存等同于连接成功。
- [选择器](../../../src/renderer/src/components/PickerDialog.vue) 区分搜索无匹配和真正没有归纳，保留搜索前的已选项；事务资料用关联、动态用引用，归纳继续用收录。
- AI 无命中只说明本次没找到，回答信息不足只判断本次摘录；建议隐私说明采用已保存服务地址，保留原有文字与图片范围。相关归纳按钮仍只打开归纳，不自动收录。
- 回顾总数说明生成时的记录数，备份提示说明完整操作已完成及附件数量，缺少本机摘要显示暂无记录；知识库加载的未知异常不再误称保存失败。
- AI 建议的「相关归纳」标签列从 44px 调整到 52px 并禁止标签自身换行，解决新增四字文案的拆行。

关于页当前的简介、作者寄语与落款保留；分类名称、导航、按钮及保存状态保持原有清楚表达。费用、密钥保护、图片参与限制、备份与导出的区别、恢复范围及不可取消说明继续保留。

## 实际验证

环境：macOS arm64、Node 24.16.0、pnpm 11.4.0、Electron 44.4.3。

- `pnpm typecheck`、`pnpm lint`：通过。最后补充截图覆盖后，类型检查及最后修改文件的 ESLint 再次通过。
- 修改文件的 Prettier 检查、文档链接与差异检查：通过。
- `pnpm test`：58 个测试文件、842 项单元与集成测试通过。新增选择器搜索状态与选择保持、加载异常重试、AI 配置未知标题覆盖；已有密钥保存与清除用例增加标题及连接状态验证。
- `pnpm build`：通过；标签列宽修正后重新构建通过。
- 真实桌面共 29 个场景取得通过结果，使用独立临时知识库、窗口配置和测试凭据。首次沙箱运行因 Electron 无法启动未进入业务场景；沙箱外全套运行 28 项通过，1 项因仍查找旧标签提示失败。同步该断言并修正标签列宽后，补跑标签、AI 建议及首页的 4 项全部通过。
- 首页桌面流程验证五类提示、空输入不插字、已有正文改分类保留、重启恢复原分类、清空后保留当前提示；原保存、搜索、抽屉编辑及真实写入失败恢复流程通过。
- 已人工检查 1280 × 900 浅色首页、1000 × 700 深色首页，以及最小深色窗口的 AI 建议截图：标题和提示完整可读，相关归纳标签保持一行。截图保存在已忽略的 `test-results/` 中。
