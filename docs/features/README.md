# 功能文档目录

本目录按功能模块组织项目的实现文档。每个功能的完整实现包含三个文档：

## 文档命名规范

```
{YYYY-MM}-{功能简称}-任务书.md
{YYYY-MM}-{功能简称}-设计.md
{YYYY-MM}-{功能简称}-交付.md
```

## 模块说明

### note-taking/

手记功能相关文档

### topic-induction/

主题归纳功能相关文档

### tagging/

标签系统相关文档

### image-handling/

图片处理功能相关文档

### ui-improvements/

界面优化相关文档

### ai/

AI 功能集成相关文档

## 使用模板

在 `docs/.templates/` 目录下有三个文档模板：

- 任务书模板.md
- 设计文档模板.md
- 交付文档模板.md

开始新功能前，复制相应模板到对应功能模块目录。
