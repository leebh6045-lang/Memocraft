# 帮助网站交付

## 实现与部署

正式源码为 `website/help/index.html`，与用户已确认的本地原型内容完全一致。单文件包含教程、样式、图形和本页示例逻辑，无外部资源、构建步骤或后台服务。

桌面教程按演示与讲解左右交替排列，依次介绍记录、分类、归纳、长期事务、搜索和备份；窄屏上下排列。示例操作不读取、修改或上传应用数据，正文内容不依赖 JavaScript。教程区分完整备份与不含草稿和图片文件的 Markdown 导出。

已通过用户本机保存的 Termius 连接部署到其 Nginx 服务器。静态文件使用独立目录，访问路径为 `/memocraft/help/`；没有结尾斜线的入口重定向到标准路径。实际地址、机器目录、登录情况与备份位置保留在本地部署记录，不作为公开仓库配置。

部署前核对上传摘要并备份受影响的站点配置；只增加教程的精确重定向与静态目录 location。配置检查成功后重载，原站点首页的响应摘要保持一致。
