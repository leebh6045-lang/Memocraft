# 帮助入口任务书

用户要求先接入桌面应用的帮助入口，使用已上线的新手指南网址。域名和 HTTPS 后续配置。

## 范围与验收

1. 左下角保持「内测中」标识，图标依次为回收站、帮助、设置。
2. 帮助使用圆圈问号，与相邻图标同尺寸、同主题颜色，支持键盘聚焦并有清楚的标题提示和可读名称。
3. 点击帮助交由系统默认浏览器打开新手指南；应用保留当前页面、正文、分类及其他编辑现场。
4. 打开调用进行中防止重复提交，完成后可以再次点击；失败显示明确提示并允许重试。
5. 仅开放固定教程入口，校验 IPC 请求来源，不允许网页或其他窗口提供任意网址。
6. 验证浅色、深色、最小窗口与专注模式，运行相关静态检查、构建和真实 Electron 流程。

## 本次边界

不新增应用内帮助页面，不修改数据库、已有保存流程、服务器配置或教程内容，不在本阶段配置域名和 HTTPS。
