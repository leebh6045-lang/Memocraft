# 帮助网站任务书

用户已确认新手指南原型，当前阶段将它整理成正式静态网页，并部署到用户已有的 Nginx 服务器。服务器暂未配置域名，实际访问地址在检查远端站点后确定。

## 目标与范围

- 提供记录、分类、主题归纳、长期事务、搜索和备份六段教程。
- 桌面上演示与讲解左右交替，手机上采用上下排列；保留简洁留白和轻量动效。
- 示例可交互，明确示例只在网页内运行，不读取、修改或上传应用数据。
- 使用已有 Nginx 提供静态访问，完成上传、配置检查与访问验证。
- 教程源码进入项目，服务器地址、登录信息和机器检查记录仅在本地保存。

## 验收标准

1. 正式页面与用户已确认的原型内容和交互一致。
2. 六段示例可操作，空白手记、无匹配搜索有明确反馈；输入内容按文本展示。
3. 桌面布局左右交替；320px 手机宽度无横向溢出；减少动态时内容和操作仍可用。
4. 页面无需额外网络资源；JavaScript 不运行时核心文字仍可阅读。
5. 上传内容与本地正式源码一致，访问实际网址可取得教程页面。
6. 如需改动 Nginx，先备份实际受影响配置，检查通过后重载，并验证已有站点相关入口。
7. 交付如实记录实际网址、验证结果与尚未完成的步骤。

## 本阶段边界

应用左下角的问号入口在网站地址确定后另行接入。本阶段不实现账号、云端知识库存储、自动同步、后台服务或访问统计；域名及 HTTPS 在具备域名后配置。
