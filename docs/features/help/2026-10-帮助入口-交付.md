# 帮助入口交付

## 用户可见行为

应用左下角依次显示「内测中」、回收站、圆圈问号、设置。问号沿用现有图标尺寸和主题颜色，悬停提示「帮助」，可读名称为「帮助（在浏览器打开新手指南）」。

点击问号在系统默认浏览器打开 `http://47.119.177.34/memocraft/help/`。应用保留当前页面与编辑内容，不提交或清理草稿。打开调用进行中阻止重复点击；失败显示「无法打开新手指南，请检查默认浏览器后重试。」，恢复按钮后可以再次尝试。

## 关键实现

- `App.vue` 增加帮助按钮、进行中状态及失败提示；`AppIcon.vue` 增加圆圈问号描边图形。
- shared 与 preload 增加无参数的 `openHelp(): Promise<Result<null>>`，普通浏览器替身返回明确不可用结果。
- `src/main/ipc/help.ts` 集中维护固定教程网址，复用原窗口、顶层 frame、完整应用地址检查，并拒绝额外参数；只允许打开此教程。
- 主窗口创建时注册帮助 IPC，窗口关闭后解除。既有导航、弹窗和 Electron 隔离策略继续生效。
- 产品规格、界面基准、项目结构和协作入口同步更新。本轮没有数据库、依赖或服务器变更。
