# 帮助入口设计

## 接入与契约

`App.vue` 在左下角的回收站与设置之间增加帮助按钮；`AppIcon.vue` 增加 `help` 描边路径，使用现有 24 坐标与 18px 图标样式。按钮提示为「帮助」，可读名称说明在浏览器打开新手指南。

`MemocraftApi.openHelp(): Promise<Result<null>>` 经 preload 调用 `help:open`。普通浏览器的桥接替身返回明确不可用结果。主进程新增 `ipc/help.ts`，注册、关闭时解除处理器；不经过存储 worker 或 services。

公开教程网址集中在主进程的 `HELP_URL` 常量，目前使用已验证的 `http://47.119.177.34/memocraft/help/`。该网址是用户要求开放的公开产品入口，不是登录凭据或私钥配置；后续域名可用时只修改这一处产品地址。

## 约束与失败流程

- IPC 复用 `isTrustedSender`，校验主窗口、顶层 frame 和完整应用地址，拒绝额外参数。
- 主进程只调用 `shell.openExternal(HELP_URL)`，不接受 renderer 提供的网址，不放开既有窗口导航和弹窗限制。
- 返回成功仅表示系统浏览器打开调用已完成，不声称网站加载或网络访问成功；页面不显示多余的成功提示。
- 浏览器打开失败使用 `UNAVAILABLE` 与可操作提示，避免复用存储失败文案或向界面泄露原始异常。
- App 持有本次打开的进行中状态，按钮禁用并在事件入口再检查，防止重复调用；错误和异常都结束进行中状态并通过既有提示条反馈。
- 外部浏览器打开不执行应用导航，不关闭抽屉，不提交或清理草稿；关闭应用时禁用帮助入口。

## 验证

独立桌面测试使用临时数据库与 userData，替换主进程 `shell.openExternal` 而不实际启动多份浏览器。验证固定网址、调用进行中防重复、完成后可重试、异常反馈以及页面和草稿保留；额外隐藏窗口调用相同 preload 能力应被拒绝。按需验证正常关闭和重启后的草稿恢复。

检查按钮在浅色、深色、最小 1000×700 窗口和专注模式下的位置与可读名称。执行项目既有类型、lint、格式、测试与构建检查，交付文档记录实际结果。
