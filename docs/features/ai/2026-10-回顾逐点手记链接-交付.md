# 回顾逐点手记链接交付

## 实现内容

「总结」「推荐」章节标题改为 20px、700 字重和主题主文字色，浅色近黑，深色保持清晰对比。新生成概要的每点正文下独立展示相关有标题手记链接，不带「来源」或正文引用编号。无标题、纯空白标题手记仍参与采样和模型分析，但不显示链接；全为空的引用组不留空列表。

模型输出 `pointSources` 二维编号组。主进程逐点校验、去重、剔除范围外编号，并仅用本次实际采样手记的本地 ID/标题回填；不接受模型生成的 ID、标题或 URL。正文继续通过关闭 HTML、链接和图片的 Markdown 渲染，手记链接用独立本地按钮。概要超长时按总预算处理分点与对应链接，不错配后续来源。

点击沿用原手记抽屉，查看的是完整正文；关闭后保留原周期、结果与阅读现场。删除的手记点击后明确提示。重新生成期间可查看旧结果；回包替换旧按钮后关闭抽屉，焦点回到新树同手记链接，没有对应入口时回「回顾」标题。原凝结、周/月选择、取消、重新生成失败保留结果均保留；焦点进出链接与抽屉不再重播凝结，见 [动效重播修复](2026-10-回顾链接动效重播-修复.md)。

迁移 `009_ai_period_sources.sql` 只为周期缓存追加可空 JSON `point_sources`，当前模式为 9，既有迁移不变。旧缓存 NULL 映射继续按原文显示，不自动调用模型、不猜造链接；用户主动「重新生成」后获得新引用。新引用随整库备份恢复，手记修改或删除不自动改写缓存。

## 兼容与限制

模式 9 库不能由旧模式应用读取，本次预览使用新的专属目录，未升级日常库。旧总结只在主动重新生成后增加链接。实际供应商是否准确选择相关编号仍需用户使用所选模型验收；程序验证编号真实性与对应关系，不声称自动判断语义相关性。
