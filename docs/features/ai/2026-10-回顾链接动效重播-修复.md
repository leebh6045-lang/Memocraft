# 回顾链接动效重播修复

## 问题与目标

点击回顾中的手记链接时，正文会重复播放凝结效果。打开、关闭抽屉或移动焦点应保留已显示的正文；真正切换周期、进入回顾或收到新结果仍正常播放凝结。未显现的操作获得键盘焦点时仍须立即清晰，不能留下透明焦点。

## 原因与方案

**原因**：逐点链接引入时，用 `.review-reveal:focus-within { animation: none }` 让焦点提前进入的块立即清晰。点击链接使焦点进入块内，规则成立并丢掉正在运行的凝结动画；抽屉取走焦点后 `:focus-within` 立即不匹配，动画声明重新生效——浏览器按新声明重放 `animation-delay` 与整个时长，用户看到已经显示过的正文又模糊着浮现一次。关闭抽屉、把焦点移回链接同样会在规则成立与失效之间反复触发。

**方案**：把"提前显现"从随焦点存在与否的 `:focus-within` 改为一次性标记 `is-revealed`。`focusin` 在 `.review-content` 上委托，给最近的 `.review-reveal` 块加上这个类，`.review-reveal.is-revealed { animation: none }` 取代原规则；焦点离开后标记仍留在元素上，动画不会重新启动。标记只存在于当轮内容树，切换周期或收到新结果时 `contentKey` 变化、Vue 挂载新节点，新块照常凝结。键盘先进入尚未显现的块依旧立即清晰，不留透明焦点。
