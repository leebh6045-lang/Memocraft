# AI 阶段二任务书：归纳建议

> 状态：纯文字初版已交付；2026-10-10 补充的**图片参与判断**（B15–B19）已实现并完成自动化与隔离桌面验证；用户已确认阶段二手动测试正常，frontmatter 更新为 `delivered`。2026-10-10 用户确认阶段一手动测试连接成功并授权进入本阶段。配套设计见 [AI 阶段二设计](2026-10-AI归纳建议-设计.md)，边界决策见 [006](../../decisions/006-归纳建议的候选与输出边界.md)。本阶段以当前文档为验收依据。
> 前置阶段：[AI 阶段一：设置与调用基础](2026-10-AI接入-任务书.md)。

## 1. 目标与范围

用户在首页写完一条手记后，点击「AI 建议」，得到**标签建议**与**可归入的现有归纳建议**，并可以一键把标签采纳到当前草稿。AI 只做提示，不自动改写草稿、不自动收录。

### 包含

- 首页编辑工具栏新增「✦ AI 建议」入口，位于「保存手记」左侧。
- 正文为空（或纯空白）时入口禁用；点击后进入加载状态并禁止重复点击。
- 建议以内联卡片出现在编辑区下方，不使用遮罩层或对话框。
- 标签建议：prompt 目标为 3–5 个、每项不超过 10 字符；合法输出为 0–8 个、每项不超过 30 字符，少于 3 个及空结果均合法。点击即加入当前草稿标签；模型返回草稿已有标签时保留并显示为已选中，不可重复添加。草稿已有 100 个标签时拒绝新增并提示。
- 归纳建议：0–3 个，**只来自知识库中已存在的归纳**，不创建新归纳、不执行收录；点击跳转到该归纳详情。
- 建议卡片可关闭；关闭后再次点击入口可重新生成。
- 草稿正文或完整有序图片图集在建议生成后发生变化时，卡片明确提示「正文或图片已修改，建议可能不再匹配」，并允许重新生成；只修改图片显示名称或草稿标签不触发过期。
- 未配置密钥、密钥无效、余额不足、限流、超时、网络异常、返回格式异常，均有明确反馈；不静默失败。

### 不包含

- 不自动触发建议（不在输入停顿时、保存时或打开首页时自动请求）。
- 不自动应用建议：标签需用户点击，归纳需用户跳转后自行收录。
- 不根据建议创建新归纳、新标签以外的实体，不修改分类、标题。
- 不做多轮追问、不做对话历史（属于阶段三问答）。
- 不做建议结果的持久化缓存（理由见决策 006）。
- 图片只在用户主动点击建议时按当前草稿图集读取；不在后台预读、不上传未纳入建议的图片。
- 不改动手记正文内容本身。
- 不支持手记详情编辑现场的建议（首版只在首页新建草稿提供）。

## 2. 实施任务

1. 共享契约新增建议相关类型与请求、取消通道；preload 暴露 `ai.suggest` 与 `ai.cancelSuggestion`，均走可信 IPC。
2. 主进程新增独立的归纳建议服务：读取模型与密钥、组装候选、调用客户端、校验输出。
3. 存储线程新增标签池查询；归纳候选复用已有 `loadTopics`，不新增归纳查询。
4. 首页新增入口按钮、建议卡片与标签采纳交互；新增 `sparkle` 图标。
5. 处理请求在途时的正文变化、重复点击、切页、关闭窗口与知识库恢复。
6. 补充单元、集成与桌面验收，完成后写交付文档。

## 4. 验证与交付记录

自动化验证使用替身客户端与隔离数据目录，不访问真实知识库、不消耗真实额度。图片修订（B15–B19）的隔离自动化结果见交付第 5 节；用户已补充真实供应商手动测试并确认正常。真实 DeepSeek 验证使用用户自己的密钥，密钥不写入文档、源码、命令参数或报告。

实际验证结果、已知限制与后续建议见 [交付记录](2026-10-AI归纳建议-交付.md)。

## 5. 依赖与风险

- 依赖阶段一已完成：模型配置、加密凭据、`DeepSeekClient`、可信 IPC 骨架与错误码。
- 依赖现有 `loadTopics` 返回的 `TopicSummary`（含 `id`、`title`、`updatedAt`）。
- 风险：归纳数量与标签池规模随知识库增长，注入 prompt 的候选必须有上限与本地预筛，不能把全部数据交给模型。
- 风险：手记正文属于用户自由文本，可能包含类似指令的内容；输出校验必须不依赖模型的自觉（见决策 006）。
- 风险：建议质量依赖模型判断，首版以「不误导」优先于「覆盖全」：宁可少给建议，不给错误归纳。
- 图片风险：渲染端只传 `draftId` 与完整图片 ID 列表；主进程须从 `loadImages(draftOwner(draftId))` 建立白名单，其他草稿、已保存手记或不存在的 ID 计入 `skippedImages`，不得调用 `readImage` 或发送字节。Reader 读取失败、损坏、超 8192 像素时继续；Pro 不读图、不自动换模型。
