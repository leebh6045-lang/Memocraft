# AI 阶段四任务书：周期总结

> 状态：实现已完成，自动化验证已通过；真实供应商手动验收待确认，保持 `in-progress`。配套设计见 [AI 阶段四设计](2026-10-AI周期总结-设计.md)。本阶段以当前文档为验收依据。
> 前置阶段：[AI 阶段一](2026-10-AI接入-任务书.md)（调用基础）、[AI 阶段二](2026-10-AI归纳建议-任务书.md)（含图片读取基础）、[AI 阶段三](2026-10-AI搜索问答-任务书.md)（取消与排空模式）。

## 1. 目标与范围

用户在「回顾」页按自然周或自然月查看一段时间内的手记积累，AI 自动生成当期主题概要与可操作建议。首次查看某时间段时自动触发生成；已生成的时间段直接展示缓存结果，用户可主动「重新生成」刷新。

### 包含

- 侧边栏四个主功能模块下方新增分隔线与「回顾」导航入口；左侧采用用户提供的 `rili.svg` 日历图形并跟随主题颜色，文字右侧靠右放置与 AI 建议相同的四角星芒，使用醒目的蓝紫粉金渐变。
- `ReviewPage.vue` 支持「按周」/「按月」切换；点击日期展开最近 12 周或 12 个月的倒序列表，选择目标周期，不列出未来项。
- 按 `created_at` 范围取当前有效手记（不含草稿、回收站、归纳、事务、动态）；手记数为零时明确告知，不调用模型。
- 手记数超过 20 条时，按四个分类各取最多 5 条送入 prompt；在 prompt 中注明总数，不截断成默认顺序前 20。
- 页面内容直接平铺在背景上，以细横线分隔「总结」与「推荐」；没有卡片，正文完整展示，加载仅用 3 行文字骨架。
- 「总结」「推荐」章节标题增大至 20px、加粗，浅色用近黑文字。总结各分点在正文下独立列出相关有标题手记链接，不显示「来源」，点击查看原手记抽屉；无标题仍参与分析但不显示链接。旧缓存保留，重新生成才补链接，增量采用迁移 009；详见 [逐点链接任务书](2026-10-回顾逐点手记链接-任务书.md)。
- 进入回顾、周/月或时间段切换、新结果出现时，只使用「凝结」入场：从模糊到清晰，依次呈现总结、推荐、底部信息；沿用滑块与高度补间，减少动态时立即显示。
- AI 概要按主题分点、配加粗短标题，作为主体；核心主题在第一点展开具体收获，其他方向简要带出，不写大段流水账或等权罗列。一般 2–4 点，内容少时可只有 1 点，给予具体适度的肯定，如实处理零散记录；最多 5 条简短可操作建议，以圆点无序列表呈现、条目不画横线，不重复正文或强行凑数。建议依据主进程提供的待办龄期与归纳收录数量等事实，不推断未提供原文、学习时长或全库统计。
- Flash 模型：每条手记最多取 1 张图片，全期最多 4 张、累计 base64 ≤8 MiB 参与摘要；超预算或不可读的图片跳过，不中止请求。Pro 模型：不发送图片，正常生成文字摘要。
- 生成结果写入 SQLite 缓存表（新增迁移 007），同一时间段可多次重新生成；**不自动失效**，用户用「重新生成」按钮手动刷新。
- 取消与排空遵循阶段二/三建立的模式：关闭窗口与知识库恢复期间取消在途请求并等待结算，恢复期间不接新请求，仍允许取消。
- 错误（网络、密钥无效、余额不足、限流、格式异常）给出明确提示与重试入口，不影响其余功能。

### 不包含

- 不做多周/多月跨期汇总。
- 不持久化「跳过的图片数量」，跳过信息只在当次响应中呈现。
- 不在建议中展示可点击的手记跳转链接（建议是自由文本，非结构化来源列表）。
- 不对历史缓存自动失效（手记被编辑、删除或添加后旧缓存仍保留，用户手动重新生成）。
- 不新增手记内容修改能力；周期总结是只读操作。

## 2. 实施任务

1. `shared/ai.ts` 追加 `AiPeriodSummary`、`AiPeriodSummaryInput` 与相关常量；`AiApi` 追加 `summarizePeriod` 与 `cancelPeriodSummary`。
2. `shared/contracts.ts` 追加三条存储操作（`loadPeriodSummary`、`fetchPeriodNotes`、`savePeriodSummary`）与相关 `StoreValue` 成员。
3. 新建 `migrations/007_ai_period_summaries.sql`，`SCHEMA_VERSION` 升至 7。
4. 新建 `storage/period-summary-store.ts`：按时间范围查手记（含图片 ID）、读写缓存。
5. 新建 `main/ai-period-summary-service.ts`：采样、图片读取、prompt 组装、输出校验、缓存写入。
6. `storage-worker.ts` 装配 `PeriodSummaryStore`。
7. `services/note-service.ts` 分发三条新存储操作。
8. `services/ai-validation.ts` 追加 `validateAiPeriodSummaryInput`。
9. `main/ipc/ai.ts` 注册 `aiPeriodSummary` 与 `aiCancelPeriodSummary` 通道。
10. `main/index.ts` 装配 `AiPeriodSummaryService`，接入关闭与恢复排空。
11. `preload/index.ts` 暴露 `ai.summarizePeriod` 与 `ai.cancelPeriodSummary`。
12. `renderer/src/api/bridge.ts` 补断开桥接不可用实现。
13. 新建 `renderer/src/composables/useReview.ts`（周期与导航现场）。
14. 新建 `renderer/src/pages/ReviewPage.vue`（含骨架屏、缓存展示与重新生成）。
15. `App.vue` 接入导航入口（分隔线 + 回顾）与 `ReviewPage` 路由。
16. 补充单元、集成与桌面测试，写交付文档。

## 3. 验收标准

| 编号 | 场景                                | 预期                                                                    |
| ---- | ----------------------------------- | ----------------------------------------------------------------------- |
| S1   | 当前时间段内手记数为零              | 显示「这段时间没有新手记」，不调用模型，不产生计费                      |
| S2   | 首次查看有手记的时间段              | 自动触发，显示骨架屏，加载完成后显示摘要与建议                          |
| S3   | 已生成缓存的时间段                  | 直接展示摘要，右下角「上次生成于 xx」，有「重新生成」按钮               |
| S4   | 点击「重新生成」                    | 绕过缓存，重新调用 AI，成功后更新缓存并更新生成时间                     |
| S5   | 按周/按月切换                       | 取消在途请求，切换后基于新时间段触发或命中缓存                          |
| S6   | 点击日期展开并选择周/月列表         | 最近 12 项倒序、选中勾与本周/月徽章明确；没有未来项                     |
| S7   | 未配置密钥                          | 显示引导提示指向设置页，不出现骨架屏或加载行                            |
| S8   | 密钥无效/余额不足/网络失败/格式异常 | 摘要位置显示明确错误提示与「重试」入口                                  |
| S9   | 关闭窗口或恢复知识库                | 在途请求被取消并等待结算；恢复失败保留窗口                              |
| S10  | 切页再回来                          | 保持当前时间段与已展示内容，不重新发起请求                              |
| S11  | Flash 模型、手记含图片              | 图片参与（最多 4 张），生成摘要包含图片上下文                           |
| S12  | Pro 模型                            | 不发送图片，正常生成文字摘要，不报图片相关错误                          |
| S13  | 从版本 6 数据库升级                 | 迁移 007 正常执行，原有内容与 AI 配置不受影响                           |
| S14  | 手记数超过 20 条                    | 按分类采样，prompt 中注明总数，AI 据此给出建议                          |
| S15  | 「按周」时间显示                    | 正确计算 ISO 自然周（周一至周日），显示格式正确                         |
| S16  | 「按月」时间显示                    | 正确计算自然月，显示格式正确                                            |
| S17  | 平铺阅读与加载                      | 正文按主题分点、首要重点展开；建议圆点列表、条目无横线，加载仅 3 行骨架 |
| S18  | 键盘选择周期                        | 首项获得焦点，方向键移动、Enter 选择；Esc 关闭并归还焦点                |
| S19  | 回顾入场、切期与新结果出现          | 分块凝结，无其他入场效果；快速切换以最后意图为准，减少动态立即清晰      |
| S20  | 侧栏回顾入口                        | 原有四角 AI 星芒在文字右侧靠右，呈醒目彩色，按钮可读名称仍为「回顾」    |

## 4. 验证与交付记录

自动化验证使用替身客户端与隔离数据目录，不访问真实知识库、不消耗真实额度。真实 DeepSeek 验证必须使用用户自己的密钥，禁止写进文档、源码、命令参数或报告；没有有效密钥时相关条目保持未验证，不以模拟成功代替。

实际验证结果、已知限制见 [交付记录](2026-10-AI周期总结-交付.md)。

## 5. 依赖与风险

- 依赖阶段一：`DeepSeekClient`、`resolveCallContext()`、`safeStorage` 凭据、可信 IPC 骨架。
- 依赖阶段二：`AiImageReader`（图片读取与预算控制）、AI IPC 暂停机制。
- 依赖阶段三：取消接替链与 `stopAndDrain()` 排空模式（直接复用结构，不重新发明）。
- **风险：prompt 规模**。自动化测试验证最多 20 条摘录、每条 200 字符及 8 MiB base64 预算，同时测量本地查询与组装。实际带图网络超时 60 秒，无图 30 秒；真实供应商延迟和 token 使用量单独手测，SQLite 规模测试不能证明模型延迟。
- **风险：建议事实来源**。「待办手记超过 7 天未处理」「归纳下有 N 条手记」等统计数字须由主进程通过存储线程查数据库计算后写进 prompt，不能让模型从手记正文自行推断。主进程需在 `fetchPeriodNotes` 返回的补充字段中包含这些统计。
- **风险：图片预算**。同一期可能有大量附图手记，必须按顺序取前 N 张而不是随机选取，预算超出时跳过后续图片而不是截断字节。
