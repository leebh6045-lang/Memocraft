# AI 自定义地址交付

设置页已加入「API 地址（Base URL）」，默认 `https://api.deepseek.com`。可填写 HTTP/HTTPS 兼容服务，支持端口、`/v1` 等子路径及完整 `/chat/completions` 接口归一化。提供「保存地址」「恢复官方」，留空保存也恢复官方；测试连接、归纳建议、搜索问答和回顾全部使用保存后的地址。

## 实现与失败处理

`domain/ai-endpoint.ts` 统一地址规则，禁止内部空白、控制字符、URL 账号密码、查询参数、片段与超长值；原始及编码后长度均受限。主进程、存储与客户端按各自边界校验，不回显非法地址；库中损坏字段报存储错误，不默默改投官方。IPC 只新增保存配置方法，没有增加渲染端任意网络能力。

地址和模型分别保存，互不覆盖；地址保存失败保留输入与原配置，模型更改与普通备份/导出后重读相同配置都不丢地址草稿。编辑清除旧测试结果，未保存地址不能测试，测试中锁定配置。主进程地址修改取消旧测试，迟到成功不能点亮新配置的验证结果；写入沿用串行队列与关闭/恢复排空。

四项调用取得 `AiCallContext { model, apiKey, baseUrl }` 快照，客户端追加 `/chat/completions`，并行调用不会相互改地址；在途业务不会因后续配置保存而改投。请求明确禁止自动跟随重定向，取消、总超时、输出校验和不自动重试保持。

追加迁移 `008_ai_base_url.sql`，模式升至 8；已有模型、手记、草稿、关系与回顾缓存保持，新增字段默认官方。地址随知识库完整备份恢复，密钥仍由系统独立加密、不进入库或备份。旧备份在恢复副本中升级，原备份不被改写。

## 实际验证

- 全量 Vitest：55 文件、769 项通过，含真实 SQLite；补充旧版 7 备份恢复用例后，地址存储专项 9 项再次通过，确认副本升级、旧 Pro 与内容保留、原备份不变。
- Vue 与普通 TypeScript、全项目 ESLint、定向格式、差异空白检查与 Electron 构建通过。
- 源码的 8 项真实 Electron 流程全部通过，约 56 秒，覆盖自定义地址全部业务、原有 AI 设置/建议/问答/回顾、取消与恢复排空。
- 最终 macOS arm64 独立包的自定义地址专项与原有 AI 设置共 2 项全部通过，约 14 秒。真实 UI 保存完整地址后四类 HTTP 请求均投向同一自定义路径，恢复官方后实际请求回到官方；验证非法输入保留、空白回默认、备份恢复、重启后配置与加密凭据可用。
- 浅色、深色及 1000×700 截图已检查，没有横向溢出。图片在 `test-results/ai-endpoint-light.png`、`ai-endpoint-dark.png`、`ai-endpoint-small.png`；源码报告为 `test-results/ai-custom-url-source-report.json`，包报告为 `test-results/ai-custom-url-package-report.json`。
- SQLite 运行时冒烟通过：Electron 44.4.3 / Node 24.21.0 / SQLite 3.53.4 / arm64。

所有验证均为临时隔离知识库、独立 userData/测试凭据和替身 HTTP，没有调用真实供应商或访问日常知识库。真实第三方服务的模型名、图片支持和 DeepSeek 请求参数兼容性需由用户填写对应地址和密钥后测试；本次不增加任意模型或其他 API 协议。Windows 未验证。

## 预览与兼容

独立应用位于 `release/ai-custom-url/mac-arm64/Memocraft.app`，双击 `release/ai-custom-url/隔离预览.command` 体验。启动器同时指定业务数据和应用配置目录，专用位置为 `.local/AI自定义地址预览/`；这是新的隔离目录，首次需要测试手记及自行配置预览密钥。此前回顾预览目录没有升级。

模式 8 无法由仅支持模式 7 的旧应用打开，数据回退需对应备份。本轮未替换已安装应用、未升级正式库；普通双击同名打包 `.app` 仍会使用正式数据路径，体验本轮应使用隔离启动器。
