# AI 阶段一任务书：设置与调用基础

> 状态：已交付。2026-10-10 用户确认已手动测试，连接成功，并同意进入阶段二。配套设计：[AI 阶段一设计](2026-10-AI接入-设计.md)。本阶段以当前文档为验收依据。

## 1. 目标与范围

在设置页配置 DeepSeek，安全保存用户 API Key、选择模型，并通过一次真实文本生成验证连接。为后续归纳建议、搜索问答、周期总结提供共用调用基础。

- 厂商固定 DeepSeek；模型为 DeepSeek V4.1 Flash（默认）与 DeepSeek V4 Pro。
- 模型选择后自动保存；API Key 通过密码输入框单独保存、更换、清除。
- 显示未配置 / 已配置，测试结果与配置状态分开。
- 测试连接只发送固定测试文字，不读取用户草稿、手记或附件；会产生少量 API 费用。
- 提供测试中的反馈与取消；错误包含未配置、密钥无效、余额不足、限流、超时、网络异常和返回格式异常。
- 请求格式/参数错误（400 / 422）与模型或接口不存在（404）分别提示并附 HTTP 状态码，不将所有请求失败归因于用户选择的模型。
- 阶段一原始范围不含三个业务功能和其他厂商。2026-10-12 自定义服务地址作为增量加入，当前范围与验收见 [自定义地址任务书](2026-10-AI自定义地址-任务书.md)。

## 2. 实施任务

1. 设置页支持两个模型选择与密钥保存、更换、清除。
2. 重启后保留已保存设置，已有知识库升级后内容与关系不丢失。
3. 密钥受系统保护，备份和导出不含密钥，恢复知识库保留本机凭据。
4. 测试连接能实际生成回答，未配置、失败和取消均有明确反馈。
5. 验证重复操作、关闭、切页和恢复期间的正确行为，失败保留输入。
6. 完成自动化与真实供应商验收，补充交付文档。

## 3. 验收标准

| 编号 | 场景                                               | 预期                                                                                                             |
| ---- | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| A1   | 首次打开设置                                       | 厂商为 DeepSeek、模型为 Flash、显示未配置；已有设置可正常使用                                                    |
| A2   | 选择 Pro 并重启                                    | 仍为 Pro；保存失败时恢复原选择并给出提示                                                                         |
| A3   | 保存、更换与清除密钥                               | 保存成功后清空输入，在输入框旁持续显示绿色勾选确认并弹出短提示；已配置状态醒目；失败保留输入；清除后重启仍未配置 |
| A4   | 检查持久化与备份                                   | 密钥仅以系统加密密文保存，SQLite、日志、备份、导出中没有密钥                                                     |
| A5   | 系统加密不可用                                     | 拒绝保存与调用，清楚提示，不影响本地记录和清除操作                                                               |
| A6   | 有效密钥测试连接                                   | 实际生成非空回答后显示成功、所选模型与耗时                                                                       |
| A7   | 无效密钥、余额不足、限流、网络失败、超时、异常响应 | 显示对应错误，不伪装成连接成功，不自动重复计费请求                                                               |
| A8   | 测试期间重复点击、取消、切页或关闭                 | 主进程限制重复请求，取消底层请求，旧响应不更新新页面                                                             |
| A9   | 恢复知识库备份                                     | 本机加密密钥仍保留；模型配置随库恢复，旧备份迁移后默认 Flash                                                     |
| A10  | 从版本 5 数据库升级                                | 原有内容与关系保留，追加版本 6 配置表                                                                            |

## 4. 验证与交付记录

自动化验证采用隔离目录、模拟 HTTP 应答与测试密钥，不访问真实知识库。真实 DeepSeek 验证必须使用有效的用户密钥，在设置页输入，禁止写进文档、源码、命令参数或报告。没有有效密钥时，A6 保持未验证，不能以模拟成功替代。

实际验证与限制在 [交付记录](2026-10-AI接入-交付.md) 中维护。2026-10-10 用户确认已手动测试，连接成功，并认可阶段一完成；用户未提供逐模型测试记录，因此不补写 Flash / Pro 分别通过的详情。

## 5. 后续阶段约定

每阶段开工前必须有独立任务书与设计文档；任务书记录范围、任务、验收及实际状态，设计文档记录架构、契约、存储、失败路径、兼容与验证。阶段结束同步验证结果，再进入下一阶段。阶段二的 [归纳建议任务书](2026-10-AI归纳建议-任务书.md) 与 [设计文档](2026-10-AI归纳建议-设计.md) 已完成实现与自动化验收；后续业务的详细接口以对应阶段设计为准。
