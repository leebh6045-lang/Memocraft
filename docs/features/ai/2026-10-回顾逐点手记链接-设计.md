# 回顾逐点手记链接设计

## 生成与契约

保留 summary Markdown 文字作为正文唯一存储，新增可选 pointSources：二维 AiAnswerSource 数组，与顶层无序列表逐点对应。undefined 表示旧缓存没有逐点引用；新结果的每个分点都有一个数组，纯事实统计而没有对应摘录时允许空数组。

模型输出 summary 的单行顶层列表和 pointSources 二维整数编号，不得在正文插引用、不生成 ID/标题/地址。主进程只将本次最多 20 条采样手记映射为真实引用，去重、剔除范围外编号；非整数、错位或越界结构整份拒绝。最多 6 个主题，概要原 600 字符预算保持，截断与引用一起按点处理，不改变主题对应关系。无标题或纯空白标题手记仍参与分析，但从链接映射中剔除，不用正文充当链接标题。

domain 的纯函数统一顶层列表拆分及持久引用结构校验。模型只返回编号，跨 worker 写缓存前再校验真实引用的字段、数量和逐点对应；损坏缓存报错保留，不伪装未命中。

## 缓存与兼容

新增迁移 009 为 ai_period_summaries 追加可空 JSON 字段 point_sources，模式版本 9；原迁移不变，原 summary 与 suggestions 不改写。NULL 读为旧缓存无引用，返回时不添加字段，兼容原段落与 Markdown。新字段随已有整库备份恢复携带；旧备份升级后保留内容。旧版本应用不能读模式 9，因此仅在本次专属隔离预览目录运行开发版，不复用日常数据目录。

## 界面与跳转

总结/推荐标题 20px、700 字重、使用 var(--text)，浅色为近黑，深色为浅色。有结构化引用时用真正 ul/li 分点，正文由关闭 HTML/链接/图片的 renderMarkdown 渲染；每点后用独立链接列表显示本地标题，蓝色文字，不加「来源」或正文编号。无引用旧缓存沿用原安全 Markdown 完整呈现。

ReviewPage 上抛 open-note，App 仅接受当前回顾引用白名单，复用 library.openNote 打开真实内容，保留原页面；失效引用显示提示。点击、键盘、busy 和抽屉焦点恢复沿用既有边界。链接纳入原正文凝结块，焦点进入时立即清晰，不改原动效节奏。

生成期间仍可查看旧结果的手记。App 记录该入口的手记 ID；回包重建旧正文树后关闭抽屉，原入口仍有效则沿用既有模态焦点恢复，否则聚焦新树内同 ID 链接，无此链接时回到「回顾」标题，避免焦点落到已移除节点。

## 验证

覆盖编号映射、去重/非法编号、错位、截断对应、无标题只分析不链接、写入/读取损坏校验；真实 SQLite 验证 8→9 保留手记和旧缓存、新引用重启/备份恢复。组件与 Electron 验证每点链接独立、无「来源」、打开正文/关抽屉回原点、删除提示、周月/再生成/凝结/深浅小窗口。测试同时隔离数据和用户配置，供应商 HTTP 使用替身。
