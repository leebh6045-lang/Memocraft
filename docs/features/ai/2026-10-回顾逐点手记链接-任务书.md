# 回顾逐点手记链接任务书

「总结」「推荐」两章标题增大、加粗，浅色主题用黑色，深色主题保持高对比。每个总结分点在正文下独立列出相关手记链接，不显示「来源」，不将链接编号混入正文；点击使用原手记详情抽屉，关闭后仍在回顾现场。

链接只指向模型实际见过的本期摘录，标题与真实 ID 来自本地。无标题或纯空白标题手记仍参与 AI 分析，但不展示跳转链接；某点只有无标题手记时只显示正文。旧缓存正常阅读，重新生成后获得逐点链接；删除的手记点击明确提示而不打开其他内容。保持周/月选择、凝结动效、重新生成失败保留结果及备份恢复行为。

开发与桌面验证同时隔离知识库和用户配置，不触碰已安装应用的数据库、密钥或附件。
