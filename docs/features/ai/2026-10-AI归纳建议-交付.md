# AI 阶段二交付记录：归纳建议

> 纯文字初版已实现并完成自动化、真实 SQLite 与隔离桌面验收，以下第 1–4 节保留此前交付记录。2026-10-10 的图片参与判断修订已实现并完成本轮自动化、真实 SQLite 与隔离桌面验证；用户随后确认阶段二手动测试均正常，详见第 5 节。初版桌面验收使用模拟 HTTP，不消耗用户额度；阶段一的真实连接测试由用户此前确认成功。

## 1. 初版已实现行为

- 首页草稿工具栏在「保存手记」左侧提供「AI 建议」；正文为空时禁用，生成中禁止重复请求。
- 建议卡片以内联方式展示标签和现有归纳。模型返回的草稿已有标签会显示为已选中；点击新标签只追加到草稿，草稿已有 100 个标签时明确拒绝采纳。
- 归纳候选由本地现有归纳预筛并限制为 30 个；标签池按有效手记的使用频次查询并限制参考总量为 40 个。模型只能返回候选 ID，标题由本地回填。
- 建议结果不写入 SQLite、不进入备份/导出/搜索。归纳点击只在草稿保存和导航成功后打开详情，不自动收录。
- 结构化输出严格校验：非法 JSON、错误类型、换行/超长标签和超量输出整份拒绝；候选外归纳 ID 丢弃；空结果合法显示。
- 请求支持独立取消、请求 ID 竞态隔离、正文变化后的过期提示；关闭卡片、切页、保存、恢复和窗口关闭不会让迟到响应覆盖新现场。
- 关闭和整库恢复暂停新的 AI 请求，并等待连接测试、建议请求及配置/凭据写入结算；恢复结束后重新开放入口。

## 4. 初版已知限制

- 本轮没有使用真实 DeepSeek 额度执行建议生成；模型质量、真实网络错误文案和供应商实际 JSON 行为仍需用户在设置页配置密钥后手动抽查。
- 当前候选预筛是标题与正文的双字窗口重叠，不是语义召回；向量检索留给后续阶段评估。
- 建议没有缓存，每次主动点击都会重新调用；这是当前草稿现场边界的既定取舍。
- 初版不发送图片；本次修订已补齐图片参与能力，状态及新增验收见第 5 节。

下一阶段仍是搜索问答；其检索、引用映射和问答输出契约不在本次交付范围内。

## 5. 修订记录：图片参与判断（2026-10-10）
