# AI 自定义地址任务书

设置页允许用户填写 API 地址，默认使用 DeepSeek 官方服务。测试连接、归纳建议、搜索问答与回顾统一使用已保存地址，支持兼容当前 DeepSeek 请求格式和模型标识的服务。

- API 地址以 Base URL 呈现，默认 `https://api.deepseek.com`，支持 HTTP/HTTPS、端口及 `/v1` 等子路径；完整 `/chat/completions` 地址也可粘贴。
- 提供「保存地址」「恢复官方」，清空后保存也回到官方。只有保存成功才生效，重启保留；未保存时不允许测试连接，保存失败保留输入及原配置。
- 更换地址使旧测试结果失效；测试中禁止更改配置，IPC 直接修改时取消旧测试。业务请求使用开始时取得的地址快照。
- 地址与模型随知识库备份恢复，密钥仍独立加密保存。既有数据库升级保留内容、关系和模型，新地址默认为官方。
- 不增加厂商选择、任意模型名或其他 API 协议，不自动重写已有 AI 结果。

验收覆盖默认官方、自定义路径与完整地址归一化、保存/重启/恢复、非法地址拒绝、失败保留、全部 AI 请求的实际目的地址、迟到结果与关闭排空。验证均使用隔离数据和替身网络。
