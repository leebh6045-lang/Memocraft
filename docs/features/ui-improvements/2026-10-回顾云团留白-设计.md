# 回顾云团留白设计

## 视觉与接入

`App.vue` 的 `.review-nav-item` 用两个伪元素分别绘制浅色、深色背景。径向渐变形成中央柔光、右上蓝色与右下杏色；渐变本身有柔和边界，无需位图或运行时模糊。

按钮建立独立层叠上下文，伪元素位于文字与图标下方，继承圆角，`pointer-events: none`。按钮裁切略放大的装饰层，自身外侧焦点轮廓仍保留。不添加模板节点，保持现有禁用与可读名称。

`theme.css` 的主题令牌控制两层透明度：常态为 0.72，悬停与选中为 1，另一主题层为 0。主题切换通过 320ms 透明度交叉过渡，避免直接替换渐变产生跳变；减少动态时沿用全局即时过渡。选中保留云团底，通过文字字重和细内描边强调状态，不再覆盖为普通灰底。

柔光流动只应用于 `.review-nav-item.active` 的两个伪元素；该类沿用 `page === 'review'` 的模板条件，无额外 JavaScript 或状态。每 10 秒以 `ease-in-out` 从横向 -1.2% 移到 1.2%，往返交替；1.03 倍轻微放大覆盖位移后的边缘。文字和图标不参与变换。离开页面即移除动画，重新进入从起点播放；减少动态下显式设为 `animation: none`、`transform: none`。

日历沿用导航文字色，星芒保留 `#8fb0d6`。仅背景视觉变化，无 IPC、存储、缓存或业务状态变更，也无新的失败路径。

## 验证计划

执行类型、lint、定向格式、既有回顾应用与页面测试及构建检查。运行既有真实 Electron 回顾动效验收，核对星芒与主题切换。用隔离测试目录另行检查常态、悬停、选中、禁用、焦点及最小窗口的截图和尺寸；观察选中后的背景变换、离开停止、再次进入及减少动态下完全静止，不向真实供应商发送手记。
