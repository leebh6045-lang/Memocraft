# 回顾云团留白任务书

## 目标与范围

侧栏「回顾」采用用户选定的「云团留白」效果：淡蓝底、中央柔光留白，蓝色与少量杏色集中在右侧边缘，让 AI 入口具有温和的视觉区别。

保留入口位置、44px 高度、日历与淡蓝星芒图标，常态可见底色，悬停与选中稍微加强。深色主题使用对应的暗蓝柔光，支持现有主题切换与减少动态偏好。当前页面为「回顾」时，背景播放与选定预览相同的轻微柔光流动；切到其他页面立即停止，文字和图标保持静止。

## 验收

- 常态、悬停、选中均保留云团效果；文字、日历和星芒清晰且对齐。
- 浅色、深色、最小 1000×700 窗口正常显示；主题切换没有浅色底突然闪入深色界面。
- 点击、键盘焦点、禁用与 `aria-current` 沿用已有导航语义；装饰不拦截操作。
- 流动仅在选中时播放，悬停不触发；离开后恢复静态，重新进入可再次播放。减少动态时背景始终静态。
- 不加载背景图片或外部资源，不增加依赖。

## 不包含

不修改回顾生成、缓存、正文入场、存储或 AI 配置，不增加新的外观选项。
