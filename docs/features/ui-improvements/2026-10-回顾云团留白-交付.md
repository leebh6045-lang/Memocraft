# 回顾云团留白交付

## 实现

侧栏「回顾」已采用云团留白：浅蓝背景中央柔光留白，右上蓝色与右下少量杏色点缀。常态即可看出区别，悬停及选中增强背景，选中保留细内描边。深色主题对应暗蓝柔光，日历、文字与右侧淡蓝星芒沿用现有导航规则。

`App.vue` 仅增加入口 CSS，伪元素绘制深浅渐变，装饰层不接收指针事件。`theme.css` 增加主题透明度令牌；320ms 交叉过渡使主题切换连续，减少动态时压缩为 1ms。

当前页面为「回顾」时，两层背景以 10 秒单程的节奏轻微横向往返流动，仅移动柔光，文字和图标静止。切到其他页面即停止；再次选中重新播放，减少动态时背景完全静态。动画直接沿用按钮现有的 `.active` 条件，无新业务状态或 JavaScript 计时器。

未增加图片、外部资源、依赖、模板节点或新的外观设置。

界面基准已同步。回顾生成、缓存、正文动效、导航与知识库生命周期均沿用原实现，无存储或数据兼容变化。

- `pnpm typecheck`、`pnpm lint`、`pnpm build` 通过。

- 另用隔离数据库检查浅色常态、悬停、选中及深色选中：透明度常态 0.72、强调态 1，另一主题层为 0；按钮高度始终为 44px。悬停在过渡完成后核对，文字恢复正文色。
- 键盘焦点保留实线轮廓；禁用仍由按钮整体透明度表达，装饰层 `pointer-events` 为 `none`，星芒描边保持 `rgb(143, 176, 214)`。
- 核对 1000×700 深浅主题截图，文字、日历及星芒完整显示，入口不撑宽侧栏。
