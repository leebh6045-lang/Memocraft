# 设置分类交付

## 实现

设置内容内增加「外观、AI 服务、数据与备份、关于」四分类，保留一级导航、工具与左下设置入口及全部原设置控件。普通入口打开外观，AI 引导直接进入服务页；按用户补充要求，不采用替换一级侧栏的原型布局。

分类底块沿用 320ms 缓动，正文先 140ms 淡出上移，再 240ms 淡入回位，四页共用稳定阅读区域。每页独立滚动，保留 AI 地址、密钥输入和保存回执；快速切换以最后选中为准。隐藏页立即设置 inert 与 aria-hidden，方向键、Home/End 同步焦点，减少动态和动画中途开启减少动态都立即清晰。

离开 AI 分类时撤销测试身份并请求取消，迟到结果不回写，已提交的保存仍处理成功或失败。数据长任务和恢复确认锁定分类；原恢复取消、不可中止、失败回滚与整库替换通知保留。

关键代码为 `SettingsPage.vue`（分类、滚动、键盘、过渡）、`AiSettingsPanel.vue`（嵌入样式和隐藏时测试清理）、`App.vue`（AI 初始分类）。未修改主进程、IPC、存储与迁移；模式版本仍为 8。

## 2026-10-13 图标替换

数据与备份改用用户提供的 `shuju.svg` 数据库图标，关于改用 `guanyu.svg` 信息图标，避免与一级菜单的手记和首页重复。`AppIcon` 保留原始路径、1024 坐标及多路径分组，菜单图标仍为 16px，填充色跟随主题和选中状态。

Vue 与普通 TypeScript 类型检查、定向 ESLint 与 Prettier、构建、36 项设置相关组件测试和 1 项现有设置桌面测试通过。隔离 Electron 中核对两图标的深浅主题、选中颜色、尺寸与装饰图标语义；16px 栅格结果与原 SVG 逐像素一致，截图已人工检查。未新增依赖、存储或迁移。

## 限制

交付为 macOS arm64 本地预览目录包，未生成新 DMG、签名、公证或验证其他平台。独立预览从专属空知识库和配置开始，不读取日常应用数据；分类切换保留现场只覆盖同一次设置页面内，离开设置仍沿用原卸载生命周期。
