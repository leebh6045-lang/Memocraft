# 设置分类任务书

按用户确认的推荐稿改进设置页，以「外观、AI 服务、数据与备份、关于」二级菜单分别呈现现有设置。用户补充约束优先：一级导航、左下角设置入口的位置以及原界面全部控件保持；分类菜单只在设置内容区域内出现，不替换一级侧栏。

- 保留主题三选、AI 模型/地址/密钥/测试、备份恢复导出、关于信息的全部控件与业务语义。
- 分类菜单常驻，选中底块连续滑动；切页淡出/淡入与原应用同节奏，快速连点以最后选择为准，减少动态时即时显示。
- 设置内切换保留 AI 未保存输入、保存反馈与每页滚动位置；隐藏页不能操作、聚焦或重复播报，离开 AI 页取消连接测试，不清除输入。
- 默认外观，从「前往设置」AI 引导进入时直接选 AI 服务；保存、取消、恢复与关闭沿用既有边界。
- 深浅主题、最小 1000×700 窗口、键盘方向/Home/End 与焦点验证正常。
- 不新增设置项，不改变数据库、一级导航顺序、设置按钮位置或其他页面。
