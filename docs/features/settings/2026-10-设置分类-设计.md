# 设置分类设计

## 页面与职责

`SettingsPage` 内部二列：左侧设置分类 tablist，右侧四个独立 tabpanel。保留页标题「设置」，不变更 App 的 nav/corner、一级控件及全局样式；App 只追加 AI 引导的初始分类参数，普通入口默认外观。

页面高度随可用窗口固定，四个子页各自滚动，菜单不跟随长表单滚走。右侧保留现有控件与状态，平铺小标题、细分隔线，减少重复的卡片边界；窄宽度时表单自动换行或分类横排，使用原有主题令牌。

## 现场与生命周期

四页通过 `v-show` 保留 DOM/组件现场，各自滚动值自然保留；非选中页立即 `inert` / `aria-hidden`，隐藏页控件不能操作、参与焦点或播报。各子页的 Vue Transition 单独跟踪取消与反向切换，避免定时器重建页面或迟到回调切回旧状态。

`AiSettingsPanel` 增加 `active` 与 `embedded` 可选 props。设置分类离开 AI 时撤销测试身份并取消对应主进程请求，忽略迟到应答，保留地址与密钥草稿及保存回执；重新进入不重新挂载或清空输入。业务保存已提交则等待原应答，在页面现场内保留结果。数据长任务与恢复确认期间锁定分类切换，沿用不可取消与失败回滚约定。

## 动效与无障碍

菜单底块按真实固定行高 44px、间距 4px，用 320ms 原缓动移动。内容用 140ms 淡出并上移 6px，新内容随后 240ms 从下方 8px 淡入；新页面在 DOM 中立即挂载且选中语义同步，动画不决定业务时机。布局保持同一阅读区域，不对不同页高做跳变。

选中项单个 Tab 停靠点，方向键循环、Home/End 首尾自动激活并同步焦点，合成输入不触发。系统减少动态时菜单和内容立即就位；动画中途启用也去除透明度/位移的起终态。数据对话框焦点仍由现有 AppDialog 管理。

## 验证

组件验证分类语义、隐藏页隔离、草稿/保存现场、AI 取消迟到、键盘焦点与恢复任务锁定。真实 Electron 使用临时独立数据与配置、测试凭据和 HTTP 替身，逐帧记录滑块与透明度，覆盖快速连点、减少动态、中途启用、每页滚动、深浅小窗与一级导航坐标不变；原有设置、AI 与备份恢复流程同步按分类操作。

只改渲染端。模式版本保持 8，不增加迁移，不接触已安装应用或正式知识库。
