# 关于页文案交付

按用户要求，设置的「关于」页移除原有发行、数据库、图片路径及底部技术说明，只呈现「项目简介」与「作者想说的话」两部分。简介为两小段，作者寄语结合用户补充的真实经历与思绪记录需求扩展为五小段，末尾另起一行「—— Ly」落款，14px 字号、右对齐、主题次要文字色。

项目简介介绍本地优先的个人知识库、随手记录、主题归纳、长期事务以及搜索与回顾。作者寄语串起学习后逐渐淡忘、零散技巧难以整理、长期事项的过程需要追溯三个真实痛点，说明项目如何从作者自身需要出发，再回到轻松记录、按自己的节奏补充整理的寄语。按用户后续要求，长期事项只概括想法、尝试、调整与进展，不举设备或工具的具体例子，也不补写用户未提供的经历或功能承诺。

日常感受段落接在长期事项之后，说明心情、生活感触和当下念头也值得记录，允许零碎或暂时没有答案的表达；以回看当时的感受与想法变化自然收尾，不点名分类或解释分类用途。结尾同步加入当下心情与对过去自己的理解，使作者寄语覆盖学习积累、日常感受与个人思考。

实现位于 `src/renderer/src/pages/SettingsPage.vue`。正文使用 15px 字号、1.85 行高与主题次要文字色，两部分以留白和细线分隔；删除失去用途的旧样式。当前规范同步更新到 [界面与交互基准](../../界面与交互基准.md)。此次仅修改静态文案与局部样式，不涉及数据、IPC 或迁移。
